# Organisms

`CMP-070..099` in `docs/plan/15-component-catalogue.md`: chrome and navigation: the app shell, nav
rail and top bar, dock panels, banners and the settings and admin layouts. A component's stories
live under `Organisms/<Component>` and ship with the component (E05-S01..S04).

## Route states

### ForbiddenState (CMP-089) and NotFoundState (CMP-090)

No keys of their own: the links follow APG Link and "Copy details" APG Button. On navigation the
host's route focus lands on the `h1` (`tabindex="-1"`); the components never move focus themselves.
An admin route without `admin:read` renders NotFoundState with the same copy as any unknown route.
