# Atoms

`CMP-001..039` in `docs/plan/15-component-catalogue.md`: buttons, inputs, typography, icons, badges
and indicators. A component's stories live under `Atoms/<Component>` and ship with the component
(E05-S01..S04).

## Keyboard

Each component's keyboard table lives here (the WAI-ARIA pattern it follows, then keys and actions).

### Button (CMP-001, APG Button)

| Keys                         | Action                                                                                                              |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| Tab / Shift+Tab              | Moves focus; focus-visible shows the ring. Plain disabled is skipped.                                               |
| Enter, Space                 | Activates (`onClick`).                                                                                              |
| Enter, Space (loading)       | No action while `aria-busy`; focus stays.                                                                           |
| Enter, Space (with a reason) | No action; the button stays focusable and its reason is the accessible description.                                 |
| Esc (reason echo)            | Hides the reason echo (CMP-016, `aria-hidden`); focus stays and the key stops there. A second Esc reaches the host. |

With a reason, hover and keyboard focus show it in a CMP-016 echo; the reason node stays the description.

### IconButton (CMP-002, APG Button; toggle button when `pressed` is set)

| Keys                         | Action                                                                                                       |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------ |
| Tab / Shift+Tab              | Moves focus; focus-visible shows the ring. Plain disabled is skipped.                                        |
| Enter, Space                 | Activates (`onClick`). Toggle mode: the consumer flips `pressed`; the name never changes.                    |
| Enter, Space (with a reason) | No action; the button stays focusable and its reason is the accessible description.                          |
| Esc (name or reason echo)    | Hides the echo (CMP-016, `aria-hidden`); focus stays and the key stops there. A second Esc reaches the host. |

Hover and keyboard focus show the name in a CMP-016 echo (D10); with a reason, one echo shows the name, then the
reason. The name stays the `aria-label` and the reason the description. Plain disabled has no echo. The echo joins
the name and the reason with " · ", e.g. "Panel settings · Owner only: your role can't use this action."

### RadioGroup (CMP-006, APG Radio Group)

| Keys                          | Action                                                                                                                     |
| ----------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| Tab / Shift+Tab               | Enters on the checked radio (the first enabled one when none is checked) and leaves the group; one tab stop.               |
| Down / Right Arrow            | Moves focus to the next radio and checks it; wraps from the last to the first, in both orientations.                       |
| Up / Left Arrow               | Moves focus to the previous radio and checks it; wraps from the first to the last.                                         |
| Home / End                    | Moves focus to the first / last radio and checks it.                                                                       |
| Space                         | Checks the focused radio; nothing on a radio with a reason.                                                                |
| Arrows (radio with a reason)  | Focus lands on it and its reason is the description; it is never checked. A plain-disabled radio is skipped.               |
| Any key (group with a reason) | No action: focus stays on the checked radio, the value never changes, no form is submitted; the reason is its description. |
| Esc (reason echo)             | Hides the reason echo (CMP-016, `aria-hidden`); focus stays and the key stops there. A second Esc reaches the host.        |

### SegmentedControl (CMP-003, APG Radio Group)

| Keys                                                  | Action                                                                                                                       |
| ----------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| Tab / Shift+Tab                                       | Enters on the checked segment (the first when none is checked) and leaves the group; one tab stop.                           |
| Right / Down Arrow                                    | Moves focus to the next segment and checks it; wraps from the last to the first.                                             |
| Left / Up Arrow                                       | Moves focus to the previous segment and checks it; wraps from the first to the last.                                         |
| Home / End                                            | Moves focus to the first / last segment and checks it.                                                                       |
| Space                                                 | Checks the focused segment.                                                                                                  |
| Alt, Ctrl or Meta + a key                             | Ignored: the browser and the host keep their shortcuts.                                                                      |
| Arrows, Home, End, Space, Enter (group with a reason) | No action: focus stays on the checked segment, the value never changes, no form is submitted; the reason is its description. |
| Any key (disabled group)                              | The group is out of the Tab order and no segment takes focus, by keyboard or pointer.                                        |

Arrow keys are not mirrored under `dir="rtl"` (Right / Down is always "next"), as for the Slider. Option values must be unique, and a computed option list needs a cast to the 2 to 6 tuple type, which defeats the compile-time bound.

### Slider (CMP-010, APG Slider)

| Keys                             | Action                                                                                                                                               |
| -------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| Tab / Shift+Tab                  | Moves focus to the thumb. Plain disabled is skipped; with a reason it stays focusable.                                                               |
| Right Arrow, Up Arrow            | Increases the value by one step.                                                                                                                     |
| Left Arrow, Down Arrow           | Decreases the value by one step.                                                                                                                     |
| Page Up, Page Down               | Increases or decreases by 10 x step.                                                                                                                 |
| Home, End                        | Sets the value to min or max.                                                                                                                        |
| Any of these (with a reason)     | No change; focus stays and the reason is the accessible description.                                                                                 |
| Esc (reason echo)                | Hides the reason echo (CMP-016, `aria-hidden`); focus stays and the key stops there. A second Esc reaches the host.                                  |
| Alt, Ctrl or Meta with any key   | Not handled; the browser and assistive technology keep their chords.                                                                                 |
| Pointer down or drag on the rail | Jumps to the pointer, then follows it, snapped to the step. While gated a press focuses the thumb, which announces the reason; nothing else changes. |

### TextInput (CMP-007, native text input)

| Keys                                                         | Action                                                                                                      |
| ------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------- |
| Tab / Shift+Tab                                              | Moves focus; the ring wraps the well. Plain disabled is skipped; read-only and a reason stay.               |
| Typing, Backspace, Delete, arrows, Home                      | Native editing; read-only allows selection and copy only.                                                   |
| Enter                                                        | The enclosing form's implicit submission (not with a reason: nothing is submitted).                         |
| Esc                                                          | Not handled: it bubbles to the host. With a reason, the first Esc hides the echo (CMP-016) and focus stays. |
| Typing, Enter, Backspace, Delete, paste, cut (with a reason) | Changes nothing; the first one of a focus visit announces the reason once.                                  |
| Arrows, Home, End, copy (with a reason)                      | Allowed and silent. Tab is never touched; Esc only hides a shown echo, and is untouched when none shows.    |

### Tag (CMP-011; the remove control follows APG Button through CMP-002)

| Keys                         | Action                                                                                                                                                           |
| ---------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Tab / Shift+Tab              | Moves focus to the remove button of a removable chip; the nested CMP-002 draws the only ring. Static chips are not in the Tab order.                             |
| Enter, Space (remove)        | Fires `onRemove`. The chip never moves focus: the owning group moves it to the next chip's remove button, else the previous one, else its input; never `<body>`. |
| Enter, Space (with a reason) | No removal; the remove button stays focusable and its reason is the accessible description.                                                                      |
| Esc (name or reason echo)    | Hides the remove button's CMP-016 echo ("Remove {label}", then the reason); focus stays. A second Esc reaches the host.                                          |

| Element                | Role        | Name                                     | Notes                                                       |
| ---------------------- | ----------- | ---------------------------------------- | ----------------------------------------------------------- |
| Chip                   | none (span) | its visible label                        | Status tones carry a fixed glyph plus the word.             |
| Leading glyph          | none        | none                                     | `aria-hidden`: the word is in the label.                    |
| Remove (ghost CMP-002) | button      | "Remove {label}", e.g. "Remove Breakout" | Gated removal: `aria-disabled` plus the reason description. |

Only a neutral label truncates. A status chip never shrinks, so give it room for its whole word.

### Badge (CMP-012, static; the `img` role when a count stands alone)

| Keys | Action                                                                                                                                                                            |
| ---- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| none | Not focusable. A standalone count is `role="img"` named `{value} {label}` (the full number, past the "99+" cap); on a labelled control, and always as a dot, it is `aria-hidden`. |

### Avatar (CMP-013, static; the `img` role when it is the only content)

| Keys | Action                                                                                                                                    |
| ---- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| none | Not focusable. Beside its visible name it is `aria-hidden`; `standalone`, it is `role="img"` named by the full label, never the initials. |

### AvatarGroup (CMP-025, static image summary)

| Keys | Action                                                                                                                                        |
| ---- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| none | Not focusable. `role="img"` named `{n} accounts: {every label}`, the names folded into `+N` included; avatars and the chip are `aria-hidden`. |

### FocusRing (CMP-039, utility; no pattern of its own)

| Keys                              | Action                                                                          |
| --------------------------------- | ------------------------------------------------------------------------------- |
| Tab / Shift+Tab                   | The ring appears on the newly focused element (`:focus-visible`).               |
| Arrow keys (roving tabindex)      | The ring moves with focus; only one ring is visible.                            |
| Pointer click / tap               | No ring on buttons and similar controls; text inputs still show it.             |
| Esc (closing a dialog or popover) | Focus returns to the trigger; the ring shows if the last interaction was a key. |

`useFocusRing({ inset? })` returns `{ className }`; `inset` draws the ring inside the element's bounds.

### Spinner (CMP-014, status region when labelled; decorative otherwise)

| Keys | Action                                                                                        |
| ---- | --------------------------------------------------------------------------------------------- |
| none | Not focusable. With `label`: a polite `role="status"`. Without: `aria-hidden` in a busy host. |

### Typography: Text, Heading, MonoText, NumericText (CMP-020, static text)

| Keys            | Action                                                                                                         |
| --------------- | -------------------------------------------------------------------------------------------------------------- |
| Tab / Shift+Tab | Skipped: static text is never focusable. Headings are reached by screen-reader heading navigation, not by Tab. |

| Element                 | Role                         | Name                                                                                          |
| ----------------------- | ---------------------------- | --------------------------------------------------------------------------------------------- |
| Text                    | none (span, or `p`)          | Its text.                                                                                     |
| Heading                 | heading, `h1`..`h6` by level | Its text; the level never follows the visual style.                                           |
| MonoText                | none (span, or `code`)       | Its text.                                                                                     |
| NumericText             | none (span)                  | The value as shown: "+420.00", "-420.00", or an unsigned "0.00". No `aria-label` on the span. |
| NumericText abbreviated | none (span)                  | The visible "1.2M" is `aria-hidden`; a visually hidden "1,200,000" is read instead.           |

### Divider (CMP-018) and Divider-Label (CMP-030), static separators

| Keys                        | Action                                                                                        |
| --------------------------- | --------------------------------------------------------------------------------------------- |
| Tab / Shift+Tab, Arrow keys | Never focusable. In a Menu, Menubar or Toolbar, arrow-key focus movement skips the separator. |

| Element               | Role      | Name                                                                          |
| --------------------- | --------- | ----------------------------------------------------------------------------- |
| Divider               | separator | Unnamed; `aria-orientation="vertical"` when vertical. Never inside a listbox. |
| Divider, `decorative` | none      | Not exposed: layout only.                                                     |
| Divider-Label rule    | separator | Its visible caption, a sibling, through `aria-labelledby` (never a child).    |

### Kbd (CMP-022, static shortcut hint)

| Keys | Action                                                                                                                                                    |
| ---- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| None | Not focusable. The caps are `aria-hidden`; the outer `kbd` reads "Control plus Shift plus K" once. Unbound: nothing renders. In a menu item it is hidden. |

| ---- | ------------------------------------------------------------------------------------------------------------- |
| None | Not focusable; a nested link or button owns its keys. A missing "—" is read as "no value" or the host's word. |

### SwatchLegendItem (CMP-037, a list item of its legend's named group)

| Keys | Action                                                                                                            |
| ---- | ----------------------------------------------------------------------------------------------------------------- |
| None | Not focusable. Read by its label and value (an abbreviation in full); the swatch and the glyph are `aria-hidden`. |

### Skeleton (CMP-015) and Skeleton-Chart (CMP-029)

| ---- | ---------------------------------------------------------------------------------------------------------- |
| None | Not focusable and `aria-hidden`; the host carries `aria-busy="true"` and the words that announce the wait. |

### ProgressBar (CMP-023, `progressbar` or `meter` role)

| Keys | Action                                                                                                 |
| ---- | ------------------------------------------------------------------------------------------------------ |
| None | Not focusable; read in reading order by its name and value (`aria-valuetext` when `valueText` is set). |

### SkipLink (CMP-085, WCAG 2.4.1 bypass blocks)

| Keys        | Action                                                                                                                |
| ----------- | --------------------------------------------------------------------------------------------------------------------- |
| Tab (first) | The first Tab on a page focuses the first skip link and shows it.                                                     |
| Tab         | To the next skip link, then into the TopBar; each link hides again when it loses focus.                               |
| Enter       | Moves focus to the target, which takes `tabindex="-1"` until blur and shows the ring; the next Tab continues from it. |

### Tooltip (CMP-016, APG Tooltip)

| Keys                          | Action                                                                                                |
| ----------------------------- | ----------------------------------------------------------------------------------------------------- |
| Tab / Shift+Tab to trigger    | Keyboard focus (`:focus-visible`) shows it at once; a pointer focus waits for the 300 ms hover delay. |
| Tab / Shift+Tab away, blur    | Hides it, unless the pointer is still on the trigger.                                                 |
| Esc                           | Hides it; focus stays on the trigger and the key stops there. A second Esc reaches the host.          |
| Pointer on trigger or tooltip | Shows after the delay and stays (WCAG 1.4.13); leaving hides it after a 100 ms grace, never a timer.  |

| Element              | Role    | Name    | Description                                                                                  |
| -------------------- | ------- | ------- | -------------------------------------------------------------------------------------------- |
| tooltip, `describes` | tooltip | —       | In the DOM at mount and `hidden`; the trigger's `aria-describedby` points at it.             |
| tooltip, `echo`      | tooltip | —       | `aria-hidden`: a visual copy of the trigger's `aria-label` or of its always-rendered reason. |
| trigger              | its own | its own | Must take focus; a static atom never hosts a tooltip. Never the `title` attribute.           |

### Popover (CMP-017, a non-modal dialog; APG Dialog (Modal) when `modal`)

| Keys                         | Action                                                                                                                          |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| Enter / Space on the trigger | Opens it; focus moves to `initialFocusRef`, else its first control, else its heading (`tabindex="-1"`), else the panel.         |
| Tab / Shift+Tab, modal       | Cycles inside, in DOM order.                                                                                                    |
| Tab / Shift+Tab, non-modal   | Through its controls; Tab past the last closes it and moves on from the trigger; Shift+Tab before the first returns and closes. |
| Esc                          | Closes it (the topmost layer: a tooltip inside takes Esc first); focus returns to the trigger.                                  |
| A press outside              | Closes it only when the press starts and ends outside; focus goes to the pressed control, else to the trigger.                  |
| Focus leaving it, non-modal  | Closes it; focus stays where it went. A modal popover takes escaped focus back.                                                 |

| Element | Role               | Name                                                                 | ARIA                                                       |
| ------- | ------------------ | -------------------------------------------------------------------- | ---------------------------------------------------------- |
| trigger | button (its own)   | its own                                                              | `aria-haspopup="dialog"`, `aria-expanded`, `aria-controls` |
| popover | dialog (portalled) | `aria-label`, `aria-labelledby` or its `heading`; one required (H11) | `aria-modal="true"` only when `modal`                      |

### Countdown (CMP-035, text with a threshold announcer)

| Keys | Action                                                                                                                                                                                   |
| ---- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

### ColorSwatch / ThemeChip (CMP-031, APG Radio Group in the picker; a static `img` otherwise)

| Keys                           | Action                                                                                                                         |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------ |
| Tab / Shift+Tab                | Enters on the selected swatch (the first enabled one when none is selected) and leaves the picker; one tab stop.               |
| Right / Down Arrow             | Moves focus to the next swatch and selects it; wraps from the last to the first.                                               |
| Left / Up Arrow                | Moves focus to the previous swatch and selects it; wraps from the first to the last.                                           |
| Home / End                     | Moves focus to the first / last swatch and selects it.                                                                         |
| Space                          | Selects the focused swatch; nothing on a swatch with a reason.                                                                 |
| Arrows (swatch with a reason)  | Focus lands on it and its reason is the description; it is never selected. A plain-disabled swatch is skipped.                 |
| Any key (picker with a reason) | No action: focus stays on the selected swatch and the value never changes; every swatch carries the reason as its description. |
| None (static `ColorSwatch`)    | Not focusable; read as the colour's name (`img`), or hidden when `decorative` beside text that names the colour.               |

Each swatch is named by the colour's human name, never its hex value. Selection is the `check` glyph, never colour alone.

Known token dependency (E05-D02 A5): there is no user-pickable palette yet, and in light
`color.drawing.selected` (Amber) is 2.76:1 on `color.surface.overlay` and 3.00:1 on `color.surface.raised`,
below WCAG 1.4.11 on a picker's own surface. Until the palette token pass lands, a light picker that offers
it sits on `color.surface.app` (3.45:1), as the ThemeLight story does.
