# Atoms

`CMP-001..039` in `docs/plan/15-component-catalogue.md`: buttons, inputs, typography, icons, badges
and indicators. A component's stories live under `Atoms/<Component>` and ship with the component
(E05-S01..S04).

## Keyboard

Each component's keyboard table lives here (the WAI-ARIA pattern it follows, then keys and actions).

### Button (CMP-001, APG Button)

| Keys                         | Action                                                                              |
| ---------------------------- | ----------------------------------------------------------------------------------- |
| Tab / Shift+Tab              | Moves focus; focus-visible shows the ring. Plain disabled is skipped.               |
| Enter, Space                 | Activates (`onClick`).                                                              |
| Enter, Space (loading)       | No action while `aria-busy`; focus stays.                                           |
| Enter, Space (with a reason) | No action; the button stays focusable and its reason is the accessible description. |

### IconButton (CMP-002, APG Button; toggle button when `pressed` is set)

| Keys                         | Action                                                                                           |
| ---------------------------- | ------------------------------------------------------------------------------------------------ |
| Tab / Shift+Tab              | Moves focus; focus-visible shows the ring. Plain disabled is skipped.                            |
| Enter, Space                 | Activates (`onClick`). Toggle mode: the consumer flips `pressed`; the name never changes.        |
| Enter, Space (with a reason) | No action; the button stays focusable and its reason is the accessible description.              |
| Esc (reason echo)            | Dismisses the reason tooltip once CMP-016 lands; until then the description is always available. |

### RadioGroup (CMP-006, APG Radio Group)

| Keys                          | Action                                                                                                                     |
| ----------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| Tab / Shift+Tab               | Enters on the checked radio (the first enabled one when none is checked) and leaves the group; one tab stop.               |
| Down / Right Arrow            | Moves focus to the next radio and checks it; wraps from the last to the first, in both orientations.                       |
| Up / Left Arrow               | Moves focus to the previous radio and checks it; wraps from the first to the last.                                         |
| Home / End                    | Moves focus to the first / last radio and checks it.                                                                       |
| Space                         | Checks the focused radio; nothing on a radio with a reason.                                                                |
| Arrows (radio with a reason)  | Focus lands on it and its reason is the description; it is never checked. A plain-disabled radio is skipped.               |
| Any key (group with a reason) | No action: focus stays on the checked radio, the value never changes, no form is submitted; the reason is its description. |

### Slider (CMP-010, APG Slider)

| Keys                             | Action                                                                                                                                               |
| -------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| Tab / Shift+Tab                  | Moves focus to the thumb. Plain disabled is skipped; with a reason it stays focusable.                                                               |
| Right Arrow, Up Arrow            | Increases the value by one step.                                                                                                                     |
| Left Arrow, Down Arrow           | Decreases the value by one step.                                                                                                                     |
| Page Up, Page Down               | Increases or decreases by 10 x step.                                                                                                                 |
| Home, End                        | Sets the value to min or max.                                                                                                                        |
| Any of these (with a reason)     | No change; focus stays and the reason is the accessible description.                                                                                 |
| Alt, Ctrl or Meta with any key   | Not handled; the browser and assistive technology keep their chords.                                                                                 |
| Pointer down or drag on the rail | Jumps to the pointer, then follows it, snapped to the step. While gated a press focuses the thumb, which announces the reason; nothing else changes. |

### TextInput (CMP-007, native text input)

| Keys                                                         | Action                                                                                        |
| ------------------------------------------------------------ | --------------------------------------------------------------------------------------------- |
| Tab / Shift+Tab                                              | Moves focus; the ring wraps the well. Plain disabled is skipped; read-only and a reason stay. |
| Typing, Backspace, Delete, arrows, Home                      | Native editing; read-only allows selection and copy only.                                     |
| Enter                                                        | The enclosing form's implicit submission (not with a reason: nothing is submitted).           |
| Esc                                                          | Not handled: it bubbles to the host.                                                          |
| Typing, Enter, Backspace, Delete, paste, cut (with a reason) | Changes nothing; the first one of a focus visit announces the reason once.                    |
| Arrows, Home, End, copy (with a reason)                      | Allowed and silent. Tab and Esc are never touched.                                            |

### Select (CMP-009, select-only combobox)

| Keys                                   | Action                                                                                                                                                                                                                 |
| -------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Tab / Shift+Tab                        | Moves focus to or from the trigger; focus never enters the list. Plain disabled is skipped.                                                                                                                            |
| Enter, Space, ↓, ↑ (closed)            | Opens the list on the chosen option, else the first enabled one. Nothing is submitted or scrolled.                                                                                                                     |
| Home / End (closed)                    | Opens on the first / last enabled option.                                                                                                                                                                              |
| ↓ / ↑, Home / End (open)               | Moves the active option; a disabled option is skipped, no wrap. `aria-activedescendant` follows.                                                                                                                       |
| Page Up / Page Down (open)             | Moves up to ten enabled options; the page never scrolls.                                                                                                                                                               |
| A printable key                        | Type-ahead (closed or open): the next label that starts with the typed string, case-insensitive. Shift+printable is typed.                                                                                             |
| Enter, Space (open)                    | Chooses the active option, closes; focus stays on the trigger. A Space right after a typed letter continues the string only while the longer string still matches; otherwise it chooses. Space never scrolls the page. |
| Enter, Space, Alt+↑ on a reason option | An unavailable or locked option is reachable but never chosen; its reason is announced on every press, not on arrival.                                                                                                 |
| Tab (open)                             | Chooses the active option, closes and moves focus on. Never chooses, or announces, an unavailable or locked option.                                                                                                    |
| Esc (open)                             | Closes with the value unchanged, focus stays; the next Esc bubbles to the host.                                                                                                                                        |
| Alt+↓ (closed) / Alt+↑ (open)          | Alt+↓ opens without moving the active option; Alt+↑ chooses the active option and closes.                                                                                                                              |
| Other Ctrl, Alt, Meta and Shift chords | Ignored; Shift plus a printable is typed, any other Shift chord is the host's.                                                                                                                                         |
| Any key above (with a reason)          | The list never opens; the first one of a focus visit announces the reason once. Tab and Esc are free.                                                                                                                  |
