## 1. Purpose, locked inputs, the rules stated once, the classification

### 1.1 Purpose

Recorded history is the only history CandleViewer has (`21` :2925: "history is only as deep as the recorder"). Every surface that reads it — the chart pane, the profile panel, journal back-fill, composite look-backs, the symbol drawer — meets the same five facts: a symbol was never recorded; recording began after the window the user asked for; recording was interrupted inside the window; older days were removed by retention; the window is covered only in part. `14` §0.5 rule 3 (:83) makes each a designed state with one stem; E16-D01 §4 (:203–207) found that stem reads like a pending job or an error and asked for heading → cause → action with the cause named per case; E11-D04 O-7 (:963) ruled the stem stays and handed the final wording here (:778, :1014); E11-D03 O-10 (:876) asks the same of SCR-044. This spec finalises the words on the ruled stem, gives `retention_purge` a treatment distinct from `never_recorded`, defines the partial-history chip as the panel's carrier of partial coverage (the chart's carrier is E12-D02's strip line and boundary, :272–273), and specifies the hatched gap band's legend, tooltip and identifiability at three zoom levels on the registered `pattern.hatch.gap` (E11-D05 :315). It decides nothing that E11-D04 §11, E12-D02 §7 / §8, E11-D05, E05-D02, E08-D04 or E16-D02 already decided (§1.2).

### 1.3 The rules, stated once (every later section with a gated control or a state cites "§1.3")

**T2 — disabled with a visible reason** (E09-D09 §2.2 :49, §3.1 :85–95, §9.1 :224, §9.3 :238; CMP-079 RbacGate `15` :811; CMP-019 Icon `lock`). A control gated by a role, grant, environment, session or **registered state** keeps its native role and its full label; `aria-disabled="true"`, never the `disabled` attribute, so it stays a Tab stop; a CMP-019 `lock` glyph (`decorative=false`, name "Not available") leads the label in the same colour; the reason sits under it (2a inline; 2b tooltip echo only for icon-only controls), in the DOM at mount and linked by `aria-describedby`; `Enter`, `Space` or a bound hotkey changes nothing and re-shows the reason once, politely; role legs are wrapped in CMP-079; the **view-as leg comes first** on every write (§2.1 step 3; `rbac.view_as` :95). Hi-fi: label `color.text.tertiary`, reason `color.text.secondary`, fill `color.surface.raised` with a `color.border.default` hairline; never `color.text.disabled`, never `opacity.disabled`. Reasons are `rbac.*` keys with the §3.2 verb (`recording:write` → "change recording", :108) or a registered state key; a screen never writes its own string, and a reason never names data — no symbol, count, balance or user name (except the view-as target) — one sentence, ≤ 60 <!-- audit:reason_max=60 --> characters, full stop.

**The sentence form is T2's rendering for an empty state whose sole CTA is gated** (E09-D09 §2.2 :49, verbatim rule; CMP-026 `15` :295; E05-D02 :1284 "a gated CTA is never drawn: the sentence form instead"): no button, **no lock glyph** (there is no control to lead), the reason sentence stands alone in `description`; `aria-describedby` is moot because no control exists. A lens that demands a lock on a sentence form is reading the wrong rule.

**The validity look is not T2** (E09-D09 §9.1 :230; E30-D02 D3 :128): a control disabled by form validity keeps its own fill and label at `opacity.disabled` (0.45 <!-- audit:opacity_disabled=0.45 -->), the reason at full opacity under it in `color.text.secondary`, `aria-disabled`, focusable; no lock, no CMP-079, no key. **No control in this spec is validity-disabled** (there is no form); the look is stated so the gate is visibly considered and never over-converted.

**Absence · status · outcome** (E09-D09 §2.1 step 1 hiding, §9.1 loading and status states; the lane's standing additions). ## 2. The pattern — anatomy, the deck grammar, the cause table

**Anatomy (cited).** SCR-151's anatomy, which SCR-047 instantiates (`14` :2916; E11-D04 §11.1 :336; E05-D02 :1271–1276): a CMP-026 block, a column at most 480 <!-- audit:layout.block_w=480 --> px, centred in its region on the host surface (`color.surface.canvas` in the pane, the panel's `color.surface.raised` elsewhere); padding `space.inset.xl`; a decorative CMP-019 glyph at `size.icon.lg` in `color.text.tertiary`; the heading `h3` (`headingLevel` 3) `type.ui.heading-sm` `color.text.primary`; the description `type.ui.body` `color.text.secondary`; the recording-start timestamp in `font.family.mono` `color.text.primary`; then `space.stack.md` and the actions: the CTA a CMP-001 `primary`, the link a CMP-021, `space.inset.sm` apart; on `backfill-in-progress` a CMP-023 `progress` under the description. Never an icon alone, never a bare "No data" (`14` :2919).

**The deck grammar (D05-D2; E16-D01 §4 :209, :214–216).** Heading = **the fact**: the ruled stem where a timestamp exists ("History starts {ts} — recording began then.", `14` :83; E11-D04 O-7 :963), its variant without a timestamp ("History starts when you record {symbol} — recording has not begun yet.", E11-D04 C-4 :919), or the reason's own heading (2, 3, the retention heading); every heading names the symbol and, where it has one, the interval (E11-D04 :347); every timestamp is text with its zone. Cause = **one sentence naming the cause**, from the closed table below, keyed by source — never an apology, never "error", never "unfortunately" (E11-D04 :778). Action = one CTA (role-resolved, §1.3) + one link; the exit that leaves the state is always available. The live-data sentence appears only with its condition (E11-D04 :351). The stem's two clauses are joined by an em dash (—), never a hyphen.

**Two families (BQ-16 RULED).** The **history-start family** (1a, 1b, SCR-151 `recording-not-started`, the auto-record countdown) carries the shared cause `empty.cause.recorded_only` — "Nothing is missing or broken: CandleViewer keeps only what it records." — one sentence reused on every surface; it replaces E11-D04 :798's "CandleViewer keeps only the data it records; nothing is missing or broken." The **gap family** (a recording gap, a refusal, a disconnect, trimmed days, no trades) never carries it: on those frames data _is_ missing from the record, so the cause names what happened (the table).
