# E15-D03 — Per-component hand-off (`16` §11.4; the contracts SCR-020's chrome changes)

Six components: **CMP-080 DockPanel**, **CMP-082 PanelHeader**, **CMP-081 DockGrid**, **CMP-073 WorkspaceSwitcher** (tab context), and the deltas to **CMP-022 Kbd** and **CMP-216 PanelMenu**. The spec is [E15-D03.md](E15-D03.md); every "§" below is the spec's. One shared checklist with a leading `Component` column replaces six literal copies. Nothing here edits `15`: Table A is copy-ready for the catalogue's owner (BQ-2). Owner approval pending; the boards are PENDING (spec §0). Numbers are the audit tool's: each is the value followed by a `<!--=…-->` anchor (`=KIND:key`, KIND = `BUDGET`, `CR` or `COUNT`) that `--json` computes and `--check` re-derives, never typed; a `{{…}}` placeholder outside a code span fails the gate.
