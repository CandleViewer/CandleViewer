## 3. Bands and the collapse (BQ-04, BQ-05, BQ-06; T:23, T:24)

**D-1 The bands** are the spec §2's: W1 … W4 on width and H1 … H3 on height, measured on the window's CSS px, the stored layout identical in each. The desktop shell opens at 1280 × 800 and sets no minimum window size (`apps/desktop/src/main/index.ts`, `createMainWindow`), so every band is reachable and none may be a dead end. **D-2 The collapse** is the spec §3's, a display transform (A41). **D-3 No hysteresis band:** the transform remounts nothing (E15-D03 N-7), so the cost of crossing 1280 repeatedly is one relayout each, and a band of tolerance would only make the rule harder to state. **D-4 The height rule** is OQ-T's, kept (`D02`:549): two conditional rows yield, the SCR-153 banner and the dock tab row never do. **D-5 Focus at the collapse** goes to the active tab when the control holding it disappears (the spec §3 item 6): the tablist is CMP-251's one `Tab` stop (`D13`:423) and the panel's region is not a stop, so the tab is where the user can act from at once; the heading was considered and not taken. **D-6 The E15 row's height** is the tool's estimate (the spec §2): E15-D03's budget gave the banner one line, which the CP-1 suggestion and its three actions do not fit at 1280 under a conservative character width, so the sweep carries the wrapped height and the tool gates a plot at every frame.
