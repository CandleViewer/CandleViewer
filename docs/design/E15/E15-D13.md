## 6. Contrast, colour vision and the measurement method (BQ-08; AC2; T:77, T:80 items 2 and 3)

**The measurement method.** The background of a sync badge or a drop zone is arbitrary: whatever panel content sits beneath it. Each such pair is therefore measured against the darkest and the lightest hosted content of each theme (E15-D03 §11.2's lo / hi, `D03`:715), over the panel surfaces `color.surface.sunken`, `.app`, `.canvas`, `.raised` and `.overlay` and a dense footprint's `color.footprint.bid`, `.ask` and `.imbalance`; the tool picks the extremes by relative luminance. ### 2.1b Dock and panel-chrome tokens (E15-D13)

Product-wide chrome promoted from E15's hi-fi (E15-D03, E15-D04, E15-D06; `docs/design/E15/E15-D13.md` §6): every addition is a Tier-2 alias of an existing primitive, with no `e15.*` namespace, and lands in the token source through E15-D13's token PR (§11.2). The reasons behind each rule are in `docs/design/specs/e15-design-system-contributions.md`.

- `space.dockgrid.gutter` = `{space.1}` (both densities): the gap between docked panels, on `color.surface.app`; never zero (the splitter's line sits in it) and never a density step.
- `space.panelheader.height.compact` / `.comfortable` = `{size.control.compact}` / `{size.control.comfortable}`: CMP-082's one header row and CMP-251's tab-group row; a panel never stacks a second header row.
- `space.dock.tray.height.compact` / `.comfortable` = `{size.control.compact}` / `{size.control.comfortable}`: CMP-250's row, present only while a panel is minimised.
- `space.workspacetabs.height.compact` / `.comfortable`: CMP-252's and CMP-249's row, a named composite of `size.control.*` + 2 × `space.inset.xs` with no JSON value (no primitive holds the comfortable value and none is added).
- `size.dock.splitter.hit` = `{size.target.min}`: CMP-083's hit band, centred on the gutter; never below the 24 px target.
- `border.focus.panel` = `{border.focus}`: the inset panel focus frame in `color.focus.ring`, painted inside the box; with the header bar (`border.thick` + `border.hairline` in `color.focus.ring`, a composite) it is the focus-affordance set. Normative: it never changes the content box (§8 rule 5) and measures ≥ 3:1 against every panel surface in both themes and high contrast.
- `color.sync.a` / `.b` / `.c`: the sync-group hues, palette references per theme and never a semantic-to-semantic alias — dark and high contrast `{palette.cyan.300}`, `{palette.amber.300}`, `{palette.purple.500}`; light `{palette.light.cyan.300}`, `{palette.light.amber.300}`, `{palette.purple.600}`; green, red and blue are excluded; the tile edge only, never a fill. **A group colour is never used without the group letter; the hue only repeats the letter.**
