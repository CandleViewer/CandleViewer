## 4. The spine: preset, saved layout, workspace

**Three nouns, one each (E15-D02 D-4; E15-D01 §5).** A **preset** is an **arrangement**: built-in, keyless, served by `listLayoutPresets` or PROPOSED for the five semantic ones (G-1), and it speaks in arrangements — "Two by two, four panels". A **saved layout** is a stored arrangement inside one workspace: named, on `Ctrl+1..9` when it holds a `hotkey_slot` (`22` :19938–:19943), listed in `[Layout ▾]` and in the gallery's Your layouts, and switched without a prompt (D-9). A **workspace** is a named document: it lives in the tab strip and the rail, is created, renamed, reordered, exported and deleted there, and never carries a layout key (AD-11). The ticket's "user presets" and "custom saved presets" are saved layouts; its "`Ctrl+1..9` behind the first nine presets" is the nine `hotkey_slot` values on saved layouts (D-1, RULED Q-7; §20).

**Placement rule (ticket Technical notes :75).** Presets live behind the layout control — `[Layout ▾]` in the tab strip's toolbar slot (SCR-020's chrome, merged E15-D03's hi-fi) — and speak in arrangements; workspaces live in the tab strip and the rail and speak in names. The gallery (SCR-022) is a setup tool, not the daily path (E15-D01 §2.1 :130); the `entry` property of `layout.preset_applied` tests that premise (§16).

**The per-frame test.** A frame blurs the spine if a preset card shows a hotkey chip, a saved layout is called a preset, a workspace name appears in the Presets listbox, the switcher shows `Ctrl+1..9`, the gallery offers a workspace action (rename or delete a workspace, Set as default, Move up / Move down), or a confirmation says "workspace" where it means "layout". The fixture's workspace Scalping shares the preset's name, so the boards cannot show a workspace name in the listbox; the tool reads the Presets rows for the other fixture workspaces (Swing 4H, Fanout review) instead. §3.2's Spine column carries the noun each frame picks — "picks an arrangement" (the Presets listbox and the gallery as a whole), "manages a saved layout" (Your layouts' rows, the key picker, the rename, delete and save-as dialogs), "switches a saved layout" (`[Layout ▾]`), "picks a saved workspace" (the rail) — and the tool reads it row by row (a frame with the wrong noun, a hotkey on a card clause, a workspace action in a gallery row or a layout key in a rail row fails by name). The lens treats a blur as a Major.

## 12. Gated controls — the one T2 statement (E09-D09 §2.1, §2.2, §3.1, §9.1, §9.3; `14` §0.5 rule 5; CMP-079; CMP-019; E30-D02 D3)
