## 3. SCR-095 — the journal analytics dashboard (R-182 `/journal/analytics`)

### 3.1 The page

Order at 1280 × 800: the h1 "Journal analytics" with the CMP-075 scope badge; the two scope rows (§3.2); the cohort bar; the headline row of eight CMP-168 tiles; the three charts (§3.4) in two columns; the breakdowns (§3.5); in the header the page-level link "How these are calculated" (`legend.page`; WD-14, `D01`:143), which opens the legend drawer at its top (§3.6), then **Manage tags** (CMP-001 secondary, `tags.manage`) and CMP-099 "Export". ### 3.2 Scope and cohort controls

- **Scope:** the line `scope.live` "LIVE only — DEMO trades are not included" (`D01`:160) under the h1, and a CMP-004 switch **Show DEMO instead of LIVE**. On, every figure, chart and table re-reads as DEMO and the line becomes `scope.demo` (`D01`:161); no LIVE figure remains (WD-2). DEMO is off by default on every visit (BQ-06). No read takes an environment today (`D01`:183, G-1 there).
- **Paper, its own scope** (`11`:4697: "live, paper and replay results are never mixed"). `is_paper` is orthogonal to the environment (`22`:21899), so without a rule a LIVE or DEMO figure could count paper fills. Paper trades are **never counted in a LIVE or DEMO figure**. A second scope row under the first reads `scope.paper_excluded` "Paper trades are not included — they have their own scope" beside a CMP-004 switch **Show paper trades instead** (`scope.paper_toggle`). On, every figure, chart and table re-reads as the paper trades of the selected environment alone, the first row's line becomes `scope.paper` "PAPER only — exchange trades are not included", a CMP-011 tag "Paper" sits beside the CMP-075 badge, and no exchange figure remains. Off on every visit (BQ-16, ruled). The two switches compose: one environment and one of exchange or paper, never a sum. SCR-095 hides paper by default behind this explicit second scope row, off on each visit, while SCR-093 shows paper as its own group by default (BQ-16): the asymmetry is deliberate and mirrors `14`'s DEMO default (`14`:2219), since an analytics figure must never take paper in unasked, while a list shows every trade in scope, grouped. Replay results are a third class (`11`:4697) and are not shown here: D01's OQ-2 keeps them out of v1 (`D01`:204). No journal read carries `is_paper` or takes a paper filter (`JournalTrade`, `22`:22578; `getJournalAnalytics`, `22`:9879): G-5.
- **Cohort bar** (CMP-055 `role="group"` "Active filters"): the set is E41-S03's (BQ-07, ruled): range (CMP-047, UTC, default the last 30 days), account (granted accounts only), symbol and tag; the environment is the scope switch above, and setup and side are not cohort filters (C-11). No analytics read takes a tag (`22`:9885–9899 takes only account ids, symbol, from and to): G-7. Each change fires `journal.analytics_filtered`, except an account change, which fires `journal.cohort_changed` alone (§10); a saved cohort is out of scope (BQ-07). "Clear filters" resets to the default.

## 6. Accessibility (`05`; WCAG 2.2 AA)

### 6.1 Roles and names

- **Landmarks:** each page's `main` is labelled by its h1; each card is a `region` labelled by its heading (CMP-050 `region`).
- **Charts:** `role="img"` named by the text summary; the context pane keeps CMP-181's DOM mirror (`15`:2336). Canvas text is never the accessible copy.
- **Tables:** CMP-049 with a caption per table; the status words (Low sample, bar-derived, auto, Manual) are cell text.
- **P&L:** sign plus the word profit or loss in the name (`05`:148); colour reinforces only (`05`:141).
- **T2:** §1 item 4; the reason node is in the DOM at mount; CMP-079 wraps every gated control, the CMP-019 `lock` named "Not available".

### 6.2 Live regions (`05`:185–186)

One polite region per page, mounted empty: "Loading analytics" then the result count ("Showing 42 LIVE trades, 1 Oct – 30 Oct"); the filter result after each cohort change; the table-view swap ("Equity shown as a table"); the T2 re-show on a key (G-T2.3); the note saved ("Note saved") or refused (`note.failed`); on SCR-094 the reconciling line once (S94-15). Nothing is assertive on these screens; no tick-rate update exists here.

### 6.3 Keyboard model (R3)

- **SCR-094:** on route entry focus lands on the h1 (`tabindex="-1"`). On S94-13 and S94-14 focus lands on the state's heading, then Retry or Back to journal. Tab order: Back to journal → Open in replay → Open chart at entry → Export → the context pane (one stop; ←/→ bar to bar, `Home` / `End`, CMP-181) → its View as table → Footprint at entry → Footprint at exit → the fills table's scroll region → the group table's links → Add note → the tag editor. `Enter` in the note field adds a line; `Ctrl+Enter` saves; `Esc` cancels and returns focus to Add note. T2 controls stay in this order (G-T2.1b).
- **SCR-095:** h1 → How these are calculated → Manage tags → Export → the DEMO switch → the paper switch → the cohort bar (range, then each filter, then Clear filters) → the eight tiles' Formula links → each chart's View as table → the breakdown SegmentedControl (arrows) → the breakdown table. The scatter table is a grid (one Tab stop; arrows; `Enter` follows the link).
- **Focus return:** the range dialog returns focus to its calendar button (`15`:559); the legend drawer returns it to the link that opened it; an export's re-auth card opens on its first credential field and, on close, returns focus to Export (§1 item 6).

### 6.4 The drawer (the ticket's note; BQ-03)

SCR-094 has no drawer variant (WD-12). The one drawer on these screens is §3.6's legend: CMP-046 non-modal (`15`:545) — on open focus moves to its heading, Tab passes through it to the page, `Esc` closes it and focus returns to the opening link; its motion is E05-D03 row 2b (`E05D03`:68), instant under reduced motion. ### 6.5 Reduced motion and reflow
