**In plain words:** the graph editor shows the same rule the form shows, read left to right as a sentence — "Check when … Only if … Then, in order …" — with the node list beside it as the rule's outline. Everything the canvas can do, the list can do. The header chip says, in four fixed words, whether the form can show this rule too; when it cannot, the nodes it cannot show carry a badge from the moment they exist. When the two editors disagree, saving and arming stop until the author picks which version to keep, in words that say what is lost.
