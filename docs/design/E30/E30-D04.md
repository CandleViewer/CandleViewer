## 20. Reduced motion: one source

Every component consumes the `16` §4 runtime contract's resolved mode and nothing else: `data-motion = safe | reduce` on the document root, written before first paint by `packages/ui/src/theme/prepaint.ts` and kept by `store.ts` (`theme.reducedMotion`), with the shipped `theme.css` setting every `transition-duration` to `0.01ms !important` under reduce (E11-D06 §9.1; E09-D08 §5.1). The override precedence is the runtime's: the in-app setting wins over the OS signal (`16` §7 :183). **No component reads the media query.** The mid-flight rule (E09-D08 §5.2): a transition already running when the mode changes completes on its own clock (≤ 200 ms here); the next one starts under the new mode. Per-element twins (the tool verifies each row of §19 has one): M1 the word + the static strip; M2 the ARMED look at frame 0; M3 and M7 unchanged; M4 the percentage text (by reference); M5 the static tick + the announcement; M6, M8, M9 instant with focus and the alert at frame 0. Under reduce the boards' insets show the same end states; the shipped runtime implements the "instant" reading of `05` §7 item 2 only (E09-D08 A-7).
