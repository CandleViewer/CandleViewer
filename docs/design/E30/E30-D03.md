## 14. Performance and feasibility notes (the engineering critique, recorded as desk notes)

- **100 ms confirm (`14` :1641):** every row is state already in the ticket (§2's data table); the only async input is the last settled preview and the modal waits for it (D2) — so the appearance is a render, not a fetch; the countdown is one timer.

- **The selector's preview cadence:** `POST /trade-groups/preview` is safe on every keystroke and rate-limited (`22` :12191ff); the ticket debounces as D02 does; the leg table and the confirm render one answer (E28-T05 ships the route, Sprint 15).
