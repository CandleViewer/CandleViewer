**Checks the review adds.**

- **State controls.** Each screen inserts a state control after the region it acts on and before the footer
  (`D02`:327). Read against the three state tables, every banner button comes first and every retry or cancel follows
  its region; no control is inserted after the footer. Verdict compliant.
- **A push never moves focus** (`05`:96). Every parent states it (`D02`:325; `D03` §7; `D04` §9; `D05` §9). The one
  move on an event is the error summary taking focus after the user's own Place (`E30D02`:308), which is a user action,
  not a push. Verdict compliant; the double speech it can cause is F-02.
- **The validity look is focusable** and a press shows the summary (`D03` §7 key table; `D04` §9). Verdict compliant.
- **`Enter` never places** on SCR-065 and SCR-069 (`D02`:665, :775); on SCR-064 `Enter` in a field applies
  (`D05` §9). Apply on SCR-064 sends a tighten only, which is never refused for want of the arm (`D06` §9), and a
  loosen goes through its own confirmation. Two grammars, each stated on its screen. Verdict compliant; recorded as
  C-02 so the builds do not merge them.

**O-6, `PageUp` / `PageDown`** (`D02`:959; inbound item 2). The drawn default is ×100 ticks. Both readings are
conformant: a spinbutton's large step is the author's to choose. The review keeps ×100 ticks, because one tick
grammar across the dialogs is easier to learn than a percentage step whose size changes with the price. The owner may
change it by exception. Closed here, answered. (RULED BQ-03)

**D05-C12, `Shift+←` / `Shift+→`** (`D05`:338; inbound item 4). `05`:72 binds "Step tick" on the DOM ladder; inside
the dialog the stop is a text spinbutton, where `Shift+←` / `Shift+→` select text. Binding a step there would break
text editing, so the dialog's `↑` / `↓` is the right binding and the two grammars do not meet: the ladder's binding is
active only while the ladder has focus (`05` §3.1 rule 2). Verdict compliant; closed here, answered. (RULED BQ-03)

**Targets** (`05`:100; 2.5.8). The smallest controls are the 24 × 24 nudge buttons at compact density (`D05` §10's
table) and the 24 px rows; the loosen confirmation's buttons are 28 px. Verdict compliant at both densities.
