## 3. The matrix: a grid, not a list of checkboxes (T §Tech; BQ-06)

**Decision.** SCR-133 is CMP-049 in `grid` mode with the host's `rowWindow` (`15`:591): `role="grid"` with `aria-rowcount` (the symbols plus the two header rows) and an absolute `aria-rowindex` on each drawn row, `aria-colcount` (the accounts plus the symbol column), the symbol as `th scope="row"`, each account as a `columnheader`, and in each cell one CMP-005 checkbox that takes focus in the cell's place (`15`:590). The nested pattern is a `gridcell` holding a checkbox, each keeping its role and its full name (`D03`:308). The checkbox is named by `aria-labelledby` pointing at three nodes already in the DOM — the column header's account, the row header's symbol and the cell's own word node — so "sub_001, BTCUSDT, allowed" (`D03B`:410) is assembled by the accessibility tree, never by a string built per cell. `aria-checked` is `true` for allowed only; "blocked" is a word in the name, not a checked state (`D03B`:410).

**Rejected: a set of labelled checkboxes with an off-screen description.** It puts every cell in the Tab order, or needs a roving model the grid already ships; it loses the row and column header announcements; and its description must be computed per cell for the whole matrix.

**The render budget** (`14`:2808, ≤ 600 ms). The name costs nothing until a cell is drawn, and only the window is drawn. At the minimum viewport of 800 px and the compact row height, with an overscan of 10 rows (PROPOSED), the window is <!-- audit:window=264 --> **264 cells** (44 rows × 6 accounts) (PROPOSED) against **2400** for the whole matrix (400 symbols × 6 accounts, `14`:2808), with three IDREFs each. Whether 264 cells, their names computed by the accessibility tree, render inside the 600 ms of `14`:2808 is E28-S02's measurement and E28-Q04's check `(heuristic)`; nothing in the naming scales with the 400 symbols.

**Settled with D03.** This is D03's own shape (`D03`:275; `D03`:280); the review adds the IDREF assembly, the window figure and the counts. The `14` line "grid cells are checkboxes with accessible names combining account and symbol" (`14`:2805) is met.
