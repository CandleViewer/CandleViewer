# E15-D01 — Observer's note template (one copy per session)

One sheet per session, filed under its session id on the private research drive, never in the repository; no real
name, account id, key fragment, balance or real position size goes on it. Times are recording times (mm:ss); anything
only said, not done, is marked "stated".

| Header field                                                                   | Entry |
| ------------------------------------------------------------------------------ | ----- |
| Session id (P1 to P6) · date · guide version (discussion guide §1)             |       |
| Profile: scalper, swing, other · role: owner, manager, viewer-like             |       |
| Displays: how many, resolution of each, OS scaling                             |       |
| Input mode: mouse, keyboard-dominant, mixed · assistive technology, if offered |       |
| Variant: standard, keyboard-dominant (guide §6), 1280×800 (guide §7)           |       |
| Consent signed · pre-session checklist done (guide §2) · time extension given  |       |

**1. Panel count observed (A1).** One row per window or monitor, counted from the screen.

| Window or monitor | Chart | Order-flow view | DOM | Tape | Ticket | Positions | Other | Floating window? |

**3. Sync expectations.** Scores go on the sync-stimuli sheet; here, how linking works in their own tool (verbatim)
and whether they asked what a group shares.

**4. Docking (B).** Method observed · frequency (stated) · the move-mode answer, verbatim. **5. Switching (E1).** Tabs,
menu, hotkey (which one) or windows · the word used for a setup.

**6. Autosave expectation (E2).** How their tool saves · after a mistaken move and a closed app they expect: saved
automatically / last saved version / asked me / other · verbatim.

**7. Variant notes.** Keyboard-dominant: K1 first key · K2 route and break point · K3 focus answer, right or wrong · K4
exit keys and any trap. 1280×800: what was hidden, clipped or given up, and any zoom.

**8. Quotes.** Verbatim only. Redaction rule: replace a name with the session id, and an account id, key fragment,
balance or position size with "[redacted]"; public symbols may stay.
