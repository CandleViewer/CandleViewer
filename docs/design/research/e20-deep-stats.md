## 7. Narrow bars: the compact form and the readout (AC 2)

### 7.1 Two different things (BQ-4)

- **Compact mode** is the user's choice of the compact row set (§6.2), a SCR-033 setting. It changes which rows show, never how a cell renders.
- **Collapse** is automatic: below a minimum legible bar width each cell drops its digits and keeps one glyph by row class: a signed row (Delta, Delta %, Cumulative Delta, Max Delta, Min Delta, CumΔ Change, OI Δ) keeps its sign glyph (`▲` / `▼`); an unsigned row (Total Volume, # Trades and the other volume, notional, count, speed, range and price rows) keeps a neutral presence mark (`·`, PROPOSED) that says only that a value exists; Delta Divergence keeps its flag glyph when true. Where a threshold is breached the cell adds the breach glyph, a shape distinct from both sign glyphs. Row labels stay. The collapse is visual only: each cell's accessible text keeps the full value, its unit, a sign word on signed rows and "beyond threshold" when breached, so a screen-reader user of the strip's `<table>` (`15`:2934) loses nothing; CMP-197 and SCR-045 stay the sighted path to the digits. Digits are never clipped or ellipsised (F-11). The width floor is E20-K01's measurement (#643), seeded from E18-D02's floors (E18-D02:124), and published by E20-D05 (#602); no number is decided here.

### 7.2 What the readout carries

For the bar under the crosshair (or the bar a keyboard user selects; E20-D04 owns those keys, G7), CMP-197 shows every enabled row's full value, in strip order, with its `24` §7 label and unit; the forming bar's values carry the provisional word. Beyond the readout's 12-row overflow (F-13) the readout shows its "+n more · Alt+T" path to SCR-045, which holds every enabled row once E20-S04 adds the Deep Stats columns; today SCR-045 lists time, OHLC, volume, delta and CVD only (`14`:1097, G6). The strip's own "read current bar's stats" shortcut (`15`:2934) reads the same values, so a keyboard user never depends on hover; its key and announcement text are E20-D04's (G7).

**Announcements.** The forming bar recomputes at up to 4 Hz (`15`:2936), so the strip, the readout and SCR-045 carry no live region for it: E20-D04 owns that policy, which the epic says “must default to non-announcing, opt-in only” (E20.json:129), and an opt-in follows `05` §6.2's polite cadence, the latest value only (`05`:184). The provisional-to-closed change is not announced per bar; the read shortcut is the on-demand path. The visual digit swap of the forming bar is capped by E20-D04 too, with the precedent “digits swap at ≤2 Hz” (`15`:1623).

### 7.3 The perceived row-count ceiling (performance note)

`(heuristic)` No perceived number is claimed: the sessions measure it (T4). The design-side ceiling is 12 rows, the point at which the readout can no longer carry every enabled row (F-13), and the component's own performance test sizes “60 visible bars × 12 rows update budget” (`15`:2938). E20-K01 measures the real cost at “13 rows and 400 visible bars” (E20.json:207) and may lower it (C5).

### 7.4 Environment

The strip reads the live public trade stream on demo and live alike (demo's public feed is “same as live (demo has no separate public feed)” `20`:871) and shows no account data; nothing in this memo differs by environment.

### 7.5 Checks E20-D02 and E20-D03 draw (no new AD)

- **Text scale and reflow:** at 200 % text and at the 400 % reflow width the strip and SCR-033 lose no row and no value; they re-lay-out (`05`:165).
- **Forced colours:** the breach shade disappears, so the breach glyph and word carry it alone (AD-5).
- **Reduced motion:** the forming bar changes only its values; no shimmer or animation marks provisional (`05`:248).
- **Target size:** SCR-033's toggles, the row menu's Move up / Move down items and drag handles have at least a 24 px hit area (WCAG 2.5.8); a collapsed glyph cell is not a target.
- **SCR-033 keyboard model and frame (PROPOSED for E20-D02, `R32`:65–66, :69–71):** on open, focus lands on the first row's checkbox; Tab runs the rows in strip order (each row's checkbox, then its Move up / Move down), then Compact mode and the threshold fields, then the footer buttons; `Esc`, cancel or confirm returns focus to the control that opened the modal; at 200 % text the row list scrolls inside the dialog and the footer stays; every SCR-033 frame is drawn at 1280 × 800.

## 8. Threshold semantics (AC 3)

**Verdict (AC 3): refuted as written.**

US-DS-003 asserts per-symbol thresholds (“each symbol uses its own and the active set is named in the legend” `11`:1918). `(heuristic)` As written, one set per symbol for every row, the assertion is refuted: it holds for absolute-unit rows and not for percent or ratio rows, which travel across symbols. The recorded recommendation to change the story is A2: "global per-row defaults; per-symbol overrides for absolute-unit rows". 60 % stays the story's seed for Delta % (`11`:1914); no other "significant" number is proposed, and no worked number is quoted: the repo holds no recorded multi-symbol trade capture (G4).

| Row class         | Rows (`24` §7 labels)                                                                                                                                                           | Threshold scope (PROPOSED)                                                                          | Why `(heuristic)`                                                    |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------- |
| Percent and ratio | Delta %, Volume Imbalance                                                                                                                                                       | one global default per row; a per-symbol override allowed, not needed                               | normalised by the bar's own volume (F-15)                            |

| Flag and price    | Delta Divergence, Bar POC, Bar VA                                                                                                                                               | no numeric threshold                                                                                | a yes/no flag or a price level                                       |

Signed rows compare the **magnitude**: "Delta % beyond 60" highlights +70 % and −70 % alike, and the side is read from the sign glyph (F-14, AD-6). E20-S03 already has both mechanisms: an `abs >` comparison that “exists because delta thresholds are usually magnitude-based regardless of sign”, and a per-symbol map where “Symbols with no set fall back to the default rather than to” none (E20.json:420). §8 adds no mechanism; it says which rows want a per-symbol override. A breach shows a shade, a glyph and a word (AD-5). C9 records that SCR-033's 0–100 % rule fits only the percent rows; G1 records that no table holds the sets.

Three or four sessions of 45 minutes: S1 the owner (P1); S2 and S3 account managers (P2a, P2b); S4, if the owner names one, a proxy order-flow trader from the owner's circle.
