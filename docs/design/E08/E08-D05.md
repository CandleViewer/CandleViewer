## 1. Surfaces, personas and the target pane

- **SCR-102 Symbol search** (modal, CMP-043 + CMP-160 over CMP-048 + CMP-213): the global switcher with
  per-result actions. Opens from `/` when no chart has focus, the TopBar trigger (SCR-010's CMP-219
  "BTCUSDT ▾"; CMP-084 beside it stays the `Ctrl+K` palette trigger) and the palette (D-1).
- **SCR-041 Quick-switcher** (non-modal popover, CMP-017 + CMP-219 + CMP-220): symbol and time interval for
  one chart, anchored to the CMP-221 toolbar symbol button (E11-D02 §2 "BTCUSDT ▾ 1m ▾"). Opens from that
  button or `/` with the chart focused (E12-D02 §5).
- **Personas** (`10` §0; permissions §7): P1 Owner (every action); P2 Manager and P3 Viewer read everything,
  a Viewer cannot write watchlists or preferences, and neither may record or refresh the catalogue (§10).
- **Target pane** (D-10): SCR-041 targets its own chart. SCR-102 targets the last-focused symbol-bound panel
  (chart or DOM ladder) **in the invoking window**, named in the header chip "Changes Chart 1 · BTCUSDT 1m"
  (plus "· sync A (3 panels)" for a sync group); with none, it reads "Opens a new chart" (E15 places it).

## 4. Matching and ranking (single source for SCR-102, SCR-041 and the palette's symbol group)

**Normalise** the query: trim, upper-case, drop spaces and `/ - _` ("btc/usdt" reads `BTCUSDT`), cap at 32
characters (`22` `q`). **Fields:** the symbol, and the base with a leading multiplier stripped
(`^1(0{1,6})(?=[A-Z])`: `1000PEPE` → `PEPE`, `1INCH` unchanged); the constant quote is never matched, so
"usd" does not hit every row. `base_coin`'s form for multiplier contracts is not verified against a fixture;
the rule gives the same result for `1000PEPE` and `PEPE`.

| Tier | Rule                                                         | Inside the tier                  |
| ---- | ------------------------------------------------------------ | -------------------------------- |
| T1   | query = symbol, or = base, or = stripped base                | tie-breaks only                  |
| T2   | symbol starts with the query                                 | tie-breaks only                  |
| T3   | stripped base starts with the query (T2 did not hit)         | tie-breaks only                  |
| T4   | stripped base contains the query                             | earlier position first           |
| T5   | query (≥ 3 characters) is a subsequence of the stripped base | shorter span, then earlier start |

**Tie-breaks**, in order: favourite; recent (newer first); 24 h turnover descending **once Q3's bulk source
exists** (skipped before, so order never depends on which panels hold a ticker); symbol in ASCII order. Only
Trading symbols rank; a non-Trading match goes to the status rule (§6.2). **Departure from the prep:** T1
includes an exact base, so "eth" ranks ETHUSDT above ETHFIUSDT without turnover data.

### 9.2 Live regions, focus and the inert background

  that path is `Esc`, then the TopBar's Tab order (A-D05-12).

## 10. Trading-domain safety

- **Error prevention:** the chip names the target before every commit and the sentence after; a modal never
  retargets another window's panel; no chart- or DOM-scoped arm moves to a new instrument unseen (D-10); a
  delisted symbol never opens a chart or a live subscription, its ladder and Record absent; auto-record and
  its refusals show before `Enter`; the env band is never scrimmed, the panic cluster stays pointer-operable
  while SCR-102 is open (D-11), and search places no orders.
- **Reconnect:** search reads the local index while disconnected; a commit is allowed and the chart shows its
  own Disconnected state (E17-D01); nothing steals focus on reconnect; delisted rows carry no stale marker.
- **RBAC** follows the server (C-2.12, C-12.4) through the session's permission set, never a role name;
  refresh is Owner-only by the contract (`instruments:write`; E08-S01's "Owner/Manager" is ticket text);
  recording follows `recording:write` (D-7). **Multi-monitor and DPI:** the dialog opens in the focused
  window, the popover is clamped to its window, and a per-monitor DPI change re-lays out at the same sizes.
