## 1. Surfaces, personas and the target pane

- **SCR-102 Symbol search** (modal, CMP-043 + CMP-160 over CMP-048 + CMP-213): the global switcher with
  per-result actions. Opens from `/` when no chart has focus, the TopBar trigger (SCR-010's CMP-219
  "BTCUSDT ▾") and the palette (D-1).
- **SCR-041 Quick-switcher** (non-modal popover, CMP-017 + CMP-219 + CMP-220): symbol and time interval for
  one chart, anchored to the CMP-221 toolbar symbol button (E11-D02 §2 "BTCUSDT ▾ 1m ▾"). Opens from that
  button or `/` with the chart focused (E12-D02 §5).
- **Personas** (`10` §7): P1 Owner (every action); P2 Manager and P3 Viewer read everything, a Viewer cannot
  write watchlists or preferences, and neither may record or refresh the catalogue (§10).
- **Target pane** (D-10): SCR-041 targets its own chart. SCR-102 targets the last-focused symbol-bound panel
  (chart or DOM ladder) **in the invoking window**, named in the header chip "Changes Chart 1 · BTCUSDT 1m"
  (plus "· sync A (3 panels)" for a sync group); with none, it reads "Opens a new chart" (E15 places it).

## 4. Matching and ranking (single source for SCR-102, SCR-041 and the palette's symbol group)

**Normalise** the query: trim, upper-case, drop spaces and `/ - _` ("btc/usdt" reads `BTCUSDT`), cap at 32
characters (`22` `q`). **Fields:** the symbol, and the base with a leading multiplier stripped
(`^1(0{1,6})(?=[A-Z])`: `1000PEPE` → `PEPE`, `1INCH` unchanged); the constant quote is never matched, so
"usd" does not hit every row. `base_coin`'s form for multiplier contracts is not verified against a fixture;
the rule gives the same result for `1000PEPE` and `PEPE`.

| Tier | Rule                                                         | Inside the tier                  |
| ---- | ------------------------------------------------------------ | -------------------------------- |
| T1   | query = symbol, or = base, or = stripped base                | tie-breaks only                  |
| T2   | symbol starts with the query                                 | tie-breaks only                  |
| T3   | stripped base starts with the query (T2 did not hit)         | tie-breaks only                  |
| T4   | stripped base contains the query                             | earlier position first           |
| T5   | query (≥ 3 characters) is a subsequence of the stripped base | shorter span, then earlier start |

**Tie-breaks**, in order: favourite; recent (newer first); 24 h turnover descending **once Q3's bulk source
exists** (skipped before, so order never depends on which panels hold a ticker); symbol in ASCII order. Only
Trading symbols rank; a non-Trading match goes to the status rule (§6.2). **Departure from the prep:** T1
includes an exact base, so "eth" ranks ETHUSDT above ETHFIUSDT without turnover data.

**Worked vectors** (unit-test ready; the four fixture symbols plus illustrative ETHFIUSDT, 1000PEPEUSDT and
1INCHUSDT; Recent = ETHUSDT, LUNAUSDT; Favourite = SOLUSDT):

### 6.4 Delisted rows (ticket AC 3)

A delisted Recent or Favourite shows the symbol struck through in `color.data-confidence.delisted.text`, a
CMP-239 `delisted` chip "Delisted by the exchange" (glyph ⊘, `.delisted.indicator`) and no 24 h cells; the
option is `aria-disabled="true"` (focusable, never `disabled`; E09-D09 T2), described by the status
sentence, present at mount. **Precedence annotation on every delisted frame:** delisted outranks
disconnected, reconnecting and stale (E08-D04 §3), so the row shows no stale or disconnected marker (the
footer's stale notice is about the catalogue). PreLaunch is not "delisted" (`22`): only the status rule
shows it. The AC's "absent" (order entry) and `14` §0.5 item 5's "disabled with a reason" (permissions)
govern different things.

### 6.5 Not-recorded disclosure (before commit)

In the detail bar for the active option and in SCR-041's preview, from `GET /recording/status`: auto-record
on → "Not recorded — a chart kept open for 60 s starts recording it." · off → "Not recorded — opening a
chart does not record it." · `symbol_cap` → "Not recorded — the recorder is at its symbol limit." ·
`disk_pressure` → "Not recorded — new recordings are paused while storage is nearly full." The Owner's
**Record this symbol…** opens M-023 (it states the disk estimate); the outcome is announced politely.

## 7. SCR-041 Quick-switcher

```text
+-- Change symbol and interval ------------------------------ Chart 1 · BTCUSDT 1m --+
| [ BTCUSDT ]  (current value, selected)                                  1 result   |
| ▌ ETHUSDT ↺     ETH / USDT      ○ Not recorded                                     |
|-----------------------------------------------------------------------------------|
| Interval  [1 1m] [2 3m] [3 5m] [4 15m] [5 30m] [6 1h] [7 4h] [8 12h] [9 1D]  More…  |
|-----------------------------------------------------------------------------------|
| tick <t> · lot <l> · max leverage <x>× · funding every <h> h · 24 h turnover —     |
| Not recorded — a chart kept open for 60 s starts recording it.  [Record this symbol]|
+-----------------------------------------------------------------------------------+
```

- **Anatomy.** CMP-017 popover below the toolbar symbol button (`color.surface.overlay`,
  `elevation.popover`, `radius.card`). The input holds the current symbol, selected: the list shows the idle
  groups until the first keystroke, which replaces the value. Rows follow §4 and §6.1 without 24 h columns.
  The strip is a `radiogroup` "Interval" of the nine default time favourites with CMP-022 digits (E12-D02
  §4); the checked one is `color.action.selected` with a 2 px `color.border.selected` inner outline (`16`
  §2.1); "More…" opens SCR-042 in place. Preview: tick, lot, max leverage and funding from the list; 24 h
  turnover per D-8.
- **States.** As §6.2, compact: loading and failed share one line plus **Retry now**; the same no-match and
  status-rule deck; a delisted current value (reached through E11-D04's **Switch symbol**) is struck in the
  input's description: "BTCUSDT is not trading on Bybit — choose another symbol.".
- **Commit.** `Enter` commits the active symbol and keeps the interval; from the strip it commits both
  (E12-D02 §5); focus returns to the invoker; the §6.2 shell sentence follows.
- **Narrow.** Width min(560, window − 32 px), shifted left to stay in the window, never over the TopBar; the
  strip wraps to two rows below 560 px and the preview to two lines.

### 9.2 Live regions, focus and the inert background

- One **polite** region per surface, empty at mount, text swapped: counts (after a 300 ms rest), loading,
  checking, no matches, status rule; the load failure is CMP-026 `error` `role="alert"`, once. Nothing in
  the list streams. A **shell polite region** outside any inert subtree speaks the commit and the Record
  outcome after the dialog unmounts; SCR-152's alert and the toast host share that layer, so a disconnect is
  heard while SCR-102 is open (my analysis: content under `inert` is hidden from assistive technology;
  E10 / E47 to confirm, A-D05-12).
- **Focus.** SCR-102 traps focus, starts in the input and returns it to the invoker on close (`05` §3.4 item
  4), or to the target panel when the invoker is gone. SCR-041 never traps. A refresh, a recorder update or a
  re-rank never moves focus or the active option (`05` §3.4 item 3).

### 9.3 Targets, zoom and motion

- **Targets:** rows, `⋯` and radio items are 24 / 32 px (`size.target.min` or more); no essential exception.
- **200 %** (1280 × 800 → 640 × 400 CSS px): the dialog is min(720, 100 vw − 32) = 608 px; columns drop in
  the order tags, base / quote, 24 h turnover, 24 h change, their values kept in the option's description
  and the detail bar. **320 CSS px:** rows become two lines at twice the height (board B27).
- **Motion:** none. Both surfaces open and close instantly in both motion modes — a departure from `16` §7's
  dialog recipe, made for the 80 ms open budget; skeleton rows are static; re-ranking is an instant swap.

word and ⊘; ARMED: word and glyph (E30-D02); direction: ▲/▼ and the sign. In light, the delisted, stale and
failure glyphs share one amber (`status.danger.strong` = `status.warning.strong`; E30-D02 CR-3): words carry them.

## 10. Trading-domain safety

- **Error prevention:** the chip names the target before every commit and the sentence after; a modal never
  retargets another window's panel; no chart- or DOM-scoped arm moves to a new instrument unseen (D-10); a
  delisted symbol never opens a chart or a live subscription, its ladder and Record absent; auto-record and
  its refusals show before `Enter`; the env band is never scrimmed and search places no orders.
- **Reconnect:** search reads the local index while disconnected; a commit is allowed and the chart shows its
  own Disconnected state (E17-D01); nothing steals focus on reconnect; delisted rows carry no stale marker.
- **RBAC** follows the server (C-2.12, C-12.4) through the session's permission set, never a role name;
  refresh is Owner-only by the contract (`instruments:write`; E08-S01's "Owner/Manager" is ticket text);
  recording is Owner-only by the ruling. **Multi-monitor and DPI:** the dialog opens in the focused window,
  the popover is clamped to its window, and a per-monitor DPI change re-lays out with the same token sizes.

### 12.2 Security

Rows show public instrument metadata only, the same for every role: no account, position, order or key
data in any row or state. The query renders through `matchRanges` over text nodes, never as markup built
from input, capped at 32 characters. A symbol check sends a path segment only after the server's own rule
(4–20 ASCII letters and digits, upper-cased), once per symbol per 60 s; the server limits unknown-symbol
refreshes too. Error copy is mapped from problem codes; `Problem.instance` is the only server string shown.
Analytics carry the query's length only.

### 12.3 Performance

The §5 budgets are measured by the consuming FE ticket's E2E (Playwright, keystroke to paint, p95) on the
reference machine (`06` §3.1) with a synthetic 500-instrument list marked as such. Search opens no
subscription; SCR-041's commit keeps the previous frame until first data (`14` SCR-041; E12-S11).
