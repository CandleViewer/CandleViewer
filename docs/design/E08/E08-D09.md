### 1.4 Rules stated once (every later row cites "R-n")

- **R-1 The backend counts; the browser reads.** Every figure comes from the backend's own accounting and the exchange's response headers, sampled at 1 Hz (`14`:2987; T:71). The browser never calls the exchange; no future design proposes it (`22`:14589 "never queries Bybit").
- **R-2 Never a zero for a value not received.** A value the source did not send shows a word ("Not connected yet", "Not received", "Error", "Unavailable"), never `0`, a blank or a green state (`E42-D02`:130 D4; `22`:22774 "never a fabricated 0"; T:59–T:63). A zero shows only when the source says it measured zero.
- **R-3 A number always carries its unit.** Requests, seconds, milliseconds, topics, characters, per cent; in the cell, the header or the accessible name (T:36–T:41).
- **R-4 The reserve is never spendable by entries, reads or backfill.** It is held back for stops, cancels and flatten (C-12.7:787–:792; `24`:2300); no figure called headroom, budget or available includes it (§7).
- **R-5 Every state is a word plus a glyph.** Colour reinforces, never carries (§16; `D12`:498 DS-CR-1).
- **R-6 Contract first, no shape.** A value with no served field is drawn as a state and recorded as a G-row with its owner; this spec never proposes a field, route or payload (C-6.1; §21.2).
- **R-7 No credential, raw body or address on the page** (§13.2; T:84–T:86).
- **R-8 Focus never moves on a refresh**, a poll, a reconnect or a `system` frame (`05`:96; `D12`:103 R-4).
