### 1.4 Rules stated once (every later row cites "R-n")

- **R-1 Data first.** A panel with any loaded row shows it; no variant here empties, covers or scrims a populated host, and the in-context forms sit in the header's status slot, outside the data rect (T AC2, T AC5).
- **R-2 Words carry every state.** Each state is a heading, a sentence or a chip word, never a colour, glyph or fill alone (`05`:125–126; D04:39–48).
- **R-3 Honest progress.** No countdown, no page count, no percentage over an unknown total: bars loaded and the target in bars, or bars loaded and the oldest date reached (BQ-5; D10-C3).
- **R-4 No internal cause.** No endpoint, status code, exchange error code or payload in any string, name or event (T Sec).
- **R-5 Reads and exits never gated.** `Retry`, `Show coverage` and every link stay enabled for every role; the one role-shaped control is the Owner's diagnostic link, absent (T3) for every other session (D09E09:38). The recorder legs stay E16-D05's (E16D5:236–240).
- **R-6 Empty costs nothing.** A CMP-026 block opens no GL context and no subscription (`14`:3059).
- **R-7 PROPOSED fields.** Frames built on D10-G1's PROPOSED `backfill` fields say so on their face and are never shown as shipped (BQ-12).
