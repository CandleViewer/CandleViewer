## 1. Pipeline (as E15-D06 / E15-D04)

1. OFFLINE, one generator per board, `gen/gen_NN.py`: `sys.dont_write_bytecode = True; sys.path.insert(0,
KIT_DIR); import e05d02kit as k`. Per component: rows of `k.cell(state, specimen, note=…)` in `k.state_row(label,
cells)`; the block `k.block(cid, rows, states=[…], not_drawn=[…], proposed=[…], ruled=[…])`; the board
   `k.board(nn, blocks, source="slice N §… Lnnn-mmm", notes=[…], not_drawn=[…])`; then
   `k.write_sheet(k.KIT_DIR / f"{k.stem(nn)}.json", bd)`, `k.compact_sheet(path)`, `k.write_board_md(nn, bd,
checks=[…], live=[…])`.
2. `write_sheet()` refuses: a specimen text that `k.say()` did not issue (every string inside a specimen plate must be
   found in the CMP's section or its slice — no invented words; record a missing one with `k.gap()`); a text-free
   board without `h`; a hug board holding text inside a non-flex board (the live lesson: it renders blank); an `inst`
   node or an icon outside `k.ICONS`; `color.text.disabled` / `opacity.disabled` on a T2 path. It packs the sections
   (`SECTION_BUDGET` 12,000 bytes json.dumps ≈ 7-8 KB compacted), writes `{board, page, sections, export, notes}`,
   runs `python3 -I ../tools/validate_sheet.py <sheet> --components ../tools/components.offline.json` and raises on exit != 0.
3. COMPACT: `k.compact_sheet(path)` runs `../tools/compact.py` into `v4/<same name>`, checks `compactOf`, that the
   page key survived, and that no compacted section passes `COMPACT_MAX` (9.5 KB; the brief's "<= ~9 KB").
4. LIVE (a later step, never in this lane): cvsheet v4.2 over cvlib v8, one section per call, then `touchTexts` +
   `relayout` + the pads fix (`S.report`), every live check in the sheet notes and the .md, then the PNG at 1x.
   **Pass `--page '<page>'` to `mkcall4.py`**: its default page for "E05-D02 / NN …" would be "E05-D02" (kit choice
   `page`; the sheet carries its page in `sheet["page"]`, the board .md repeats it).

## 3. Board anatomy (every board; `k.board()`)

- **Root** `E05-D02 / NN <slug>`: a flex column on `color.surface.app`, `space.inset.lg` padding and gap, width fixed
  by the kit, height hugging. **Head**: the name (`type.ui.heading-md`), "Source: …" (the slice sections the board
  draws), the theme line, "File E05-D02 boards · page …". **Body**: the specimen grid (blocks wrapping, `cols=` per
  row or as many as fit, max 5,720 px) beside the **annotation column**. **Footer**: "file E05-D02 boards · page … ·
  board NN · r1".
- **Specimen block** (`k.block`): one per component, a `color.surface.canvas` card with a 1 px `color.border.subtle`
  edge (the edge must read: lesson), `radius.card`, `space.inset.lg`; it holds the title (the spec's Penpot name, e.g.
  `CMP-047 · DatePicker`; " (light)" on board 10), the caption "CMP-0xx · slice N Lnnn-mmm · tokens: …" (default the
  tokens the section cites that the file holds, `k.tokens(cid)`; pass `toks=` to narrow it), an optional note, the
  stamp pills, then the state rows.
- **State row** (`k.state_row`): a 120 px row label (`type.ui.label`, `color.text.secondary`: the variant, size or
  axis value) and its cells. **Cell** (`k.cell`): the specimen on a `color.surface.app` plate (`space.inset.md`,
  `radius.control`; slice 1 §1.1's matrix cells) and its caption (the state, " — note") in `type.ui.caption`
  `color.text.secondary`, wrapping at the plate width (min 160 px). A text-free specimen gets an explicit plate `h`.
- **Shared pieces**: `k.focus_ring(n)` (CMP-039: 2 px `color.focus.ring`, `border.focus`, 2 px outside, radius.md =
  control + 2; a flex wrapper with the ring as an abs rect, so text never sits in a non-flex board);
  `k.t2_label(label)` (lock LEADS the full label, both `color.text.tertiary`), `k.t2_reason(reason)` (2a,
  `type.ui.caption` `color.text.secondary`), `k.t2_inline(control, reason)`, `k.T2_SHAPE` (the stripped shape:
  `color.surface.raised` + 1 px `color.border.default`), `k.lock_badge(control)` (2b: icon-only, `size.icon.sm` lock
  bottom-right, the control never grows) with `k.tooltip(reason)` as the echo; `k.button(label, variant, state)`
  (CMP-001 composed: six variants, seven states, T2 with `reason=`; boards 08/09/10 reuse it for actions);
  `k.spinner()` (CMP-014 static frame), `k.pill()`, `k.tglyph()`, `k.lock()`, `k.caption()` (a long caption needs a
  fixed width), `k.say()` for every specimen string, `k.gap()` for a missing one.
- **T2 (binding; E09-D09 §2.2):** every gated cell (`disabled-with-reason`, "T2 …" cells, CMP-079 Allowed=false) keeps
  its full label and native shape, the lock leads the label, label + lock `color.text.tertiary`, the reason under it
  (2a) or echoed by CMP-016 (2b icon-only); never `color.text.disabled`, never `opacity.disabled` on label, glyph or
  reason (`write_sheet` refuses it on any node whose path holds "T2" or whose name holds "reason": name gated nodes
  so). Reasons are the specs' `rbac.*` strings via `k.say()` (e.g. "Owner only: your role can't use this action.",
  slice 1 CMP-001 names table). Plain `disabled` (availability) is the only `opacity.disabled` use.
- **Annotation column** (`k.annotation`, 400 px, canvas card): **Sources** (each block's CMP section span, each slice's
  conventions / exceptions / decisions sections with the repo path @ 966f9edcd, E09-D09 §2.2, then `sources=`);
  **Stamps** (each block's PROPOSED / RULED); **Not drawn — the text is binding** (each block's `not_drawn`, then
  the board's `not_drawn=`); **Kit choices** (the keys used); **Notes** (`notes=`).
- **Stamps** (`proposed=` / `ruled=` on `k.block`): PROPOSED = an item of the slice's "Decisions for the owner"
  section (slice 1 A1-D17, slice 2 E1-E27 plus the carried A/B/C, slice 3 G1-G23, slice 4 H1-H37; another slice's
  as "s1:D13"), drawn as an amber outlined pill "PROPOSED · … (owner approval pending)" wherever a cell draws that
  proposal (e.g. s1 D13 gated form now T2, D16 buy/sell arrows, A12 inverse labels; s3 G23 lock colour; s4 H1 scrim).
  RULED = a ruling the slice text cites (e.g. "E13-D04's BQ-16", "#3925"), checked by `found()` in the slice, drawn
  as a neutral pill. Slice text says "OWNER APPROVAL" for some items: stamp them PROPOSED with their decision id.
