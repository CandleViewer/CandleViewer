### 1.4 Rules stated once (every later row cites "R-n")

- **R-1 Never approximate (BQ-28).** No state builds non-time bars from klines or an estimate and no action offers it: the only exits are the merged ones (`Switch to time bars`, `Go to recorded history`, `Build earlier bars`, `Record this symbol`). Every state reads as a statement of fact, never an apology (E16-D05:165).
- **R-2 No infinite spinner.** Every wait states a bound, a next-attempt time or the condition that ends it (per the `14` design sign-off checklist, `14`:1102); a spinner alone is never shown.
- **R-3 No new data-confidence state.** Stale, reconnecting and disconnected are E08-D04's states (E08-D04:41–48) as E11-D02 §10 renders them, consumed unchanged; rebuilding, partial history and the outcome notices are E12's own slots, not feed states (`14`:743).
- **R-4 One meaning per slot, one primary indicator.** The strip shows one line (D02:31; `14`:743); every other state keeps its own slot and stays in text.
- **R-5 Never colour alone.** Every state carries text, a dash pattern or a glyph; de-emphasis is a dash pattern, never opacity alone (D02:296).
- **R-6 The server decides.** Hiding a CTA is presentational; `recording:write` and the rebuild registry's owner check decide (C-2.12; ADR33:158).
- **R-7 Nothing leaks.** Error words are this spec's copy keyed by `code`; no host, URL, SQL, stack trace, `Problem.detail` or `ret_msg` is shown (E11-D04:386).
