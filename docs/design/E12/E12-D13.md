## 1. Method and evidence (RULED BQ-07, BQ-08, BQ-22)

Nothing in the pass reaches an exchange or any external host (C-13.5): the run's refused-request list was empty.
- **Run kind** of a capture or geometry row: `emulated` (headless Chromium 156, viewport 2560x1440, device scale factor 1, 1.25 and 2, reduced motion on) or `owner-run`. No row lets a reader take one for the other.
- **Row status:** `compared`, `compared-in-part`, `pass`, `fail`, `deferred-owned`, `owner-run`, `not-comparable-yet`, `known` (the row restates an earlier record, cited) and `out-of-scope (unbuilt)`. A `fail` carries class, severity, owner and target (§12). A `deferred-owned` row names its owner story and appears in the re-run table (§14).
- **Severity** (RULED BQ-17): **Blocking** — a `05` clause or WCAG A or AA failure with no compliant path, the reader-blocking P0 of `T a11y`, a state carried by colour alone, a geometry miss that makes a mark unreadable; **Major** — a spec line violated with a workable path; **Minor** — a tolerance-edge or wording drift; **Info** — a note. Only the P0 class and AC5's P1 class become filed Bugs.
- **Fixtures** are named, never pasted: the bars of `FIX` tape `btcusdt-2026-09-01` (busy) and `ethusdt-2026-09-03-thin` (quiet) for the series; the BTCUSDT, ETHUSDT and SOLUSDT instrument rows of the merged switcher suite for SCR-041; a fixed reference value for the card's correlation reference. The bank is synthetic and public-shape only.
- **Captures** (RULED BQ-22): 7 <!-- audit:ca=7 --> PNGs under `docs/design/E12/img/`, each a fixture-only rendering of a built surface, checked by eye for anything that is not a fixture value before it was kept. The measured number is the evidence; the image shows it. No board, no Penpot page.
- **Type in the captures.** The capture page loads the token CSS exactly as the app does (the same five style entries as `apps/web/src/main.tsx`), and every bound text resolves to its type token (§7). No face is shipped with it: the two families name no `@font-face` and no generic fallback (`UIR`:283-284), so on the capture host, which has neither family, every text draws Chromium's last-resort serif. The captures show the built surfaces as they render on such a host; that is a finding of the build (DF-6), not a fault of the page, so they are not re-captured with faces the build does not supply.

### 1.1 Method: the capture run

The collector is scratch code, never committed (RULED BQ-07); this subsection is enough to rebuild it.

- **Versions.** Headless Chromium 156.0.8078.4 driven by Playwright 1.64.1 (`@playwright/test`); axe-core 4.14.0 through `@axe-core/playwright` 4.14.0; Node 20.19.5; the app's own Vite config serving `apps/web` on 127.0.0.1.
- **Files.** `index.html` and `main.tsx` (the harness page, placed under `apps/web` for the run and removed after); `drive.mjs` (the capture driver); `dpcb.mjs` (the device-pixel box read of GE-15); `probe.mjs` (this round's type and spacing probe).
- **Page.** `main.tsx` imports the five style entries `apps/web/src/main.tsx` imports (the dark, light and high-contrast token CSS, `theme.css`, `components.css`), sets `data-theme` and `data-density="comfortable"` on the root and pins `crypto.randomUUID` to the fixed reference value. SCR-030 is `<Chart>` with 120 bars of `FIX`'s `btcusdt-2026-09-01` `time-1` in an 800x450 box; SCR-048 is `<ChartErrorSurface>` in the same box with `getContext("webgl2")` returning null, and the badge is reached by clicking `Continue with basic rendering`; SCR-041 is `<QuickSwitcher>` over a stub index of the three instrument rows, role `owner`, ETHUSDT in Recent, opened by its trigger and clipped to 600x260.
- **Driver.** One browser context per surface, theme and DPR (viewport 2560x1440, reduced motion); every non-loopback request is aborted and listed; the box is screenshotted; axe runs at DPR 1 with the tags of §10.3; for KR-8, Tab is pressed four times from the page body and the focused element and its outline are read.
- **Probe.** On the same page at DPR 1, dark and light: the computed `font-family`, size, weight, line-height and padding of each text element of the card, the badge and the host, and the faces Chromium drew for it (`CSS.getPlatformFontsForNode`); run once as built and once with the two families supplied through `@font-face` from local copies of the same families (Inter 4.001, JetBrains Mono 2.304), loopback only.

## 15. The design-QA procedure (RULED BQ-24)

- **PS-1 Inputs.** The epic's hand-off pack (per-surface entries, manifests, deck), the specs it cites, the token JSON and the merged suites; each lifted by content at the base, never retyped.
- **PS-2 Base.** One `main` commit; every cite pinned to its words; unmerged parents named only, each a delta row.
- **PS-3 Observation.** Source, merged suites, and a loopback stub-run of the built components with fixtures only; what needs a physical monitor, a shell build, a deployed build or a speaking reader is owner-run and named.
- **PS-4 What exists.** Each surface `compared`, `compared-in-part` or `deferred-owned (story)`; never a second desk review of an unbuilt design.
- **PS-5 Geometry.** Device pixels at the ladder samples and the scale factors; the formulas evaluated by the tool; the tolerance per quantity; an emulator reading the tool cannot trust is an owner-run row.
- **PS-6 Matrix.** A covering set with a risk reason per row; agreement is a comment, not a claim.
- **PS-7 Rows.** One finding, one id; a known record cited, not restated; class, severity, clause, owner (spec and area), target, sentence with its cite, reason.
- **PS-8 Decision.** The pass decides each divergence; an accepted row edits `14` by one line; `15` changes are A-rows.
- **PS-9 Routing.** A comment on each owning story; a Bug only for the P0 and AC5 P1 classes.
- **PS-10 Re-run.** Keep the re-run table; each build merge re-runs its rows; the ticket closes when the table is empty.
