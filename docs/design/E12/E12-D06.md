## 1. Geometry (px derived from bar spacing s)
- body = clamp(round(s x 0.7), 1, 24), forced odd when >= 4. wick = max(1, round(body / 6)), forced odd when > 1, centred. Cap: butt.
- LOD (26-chart-engine-design 3.6): s >= 3 L0 (wick + body); 1.5 <= s < 3 L1 (bodies, 1 px, no wick); s < 1.5 L2 min/max column per pixel
  (high-low in 42% tint, first-open..last-close span; down solid, up dotted every 2nd px). +-15% hysteresis.
- Doji (O = C): 2 px (1 px under s 8) neutral `color.candle.wick`, never up/down colour. Zero-range (O=H=L=C): max(body,3) x 2 px, neutral; 1 px dot below s 3, kept by min/max.
- OHLC bar: stem 1 px up / 2 px down, ticks max(2, floor(body/2)) each side.
- Line/area/baseline: 2 px round-join polyline at bar centres; area fill 16% alpha; baseline fills 22% up/down split at exact crossings, dashed 1 px base line.
- Heikin-Ashi: standard HA formulas, candle geometry, persistent text chip "HA derived"; crosshair, drawings and orders anchor to REAL time/price; mirror announces real OHLCV first, HA close as second clause.
- Gap (drawn, see §0 status): hatched band + two dashed verticals + text range; the line/area/baseline split into segments; nothing interpolates. Differs from E12-D08's partial-history edge.
- Equi-volume width = clamp(round(volume / median x 14), 6, 48); cap rule in the frame. Non-time axes: labels at bar/brick boundaries (frame pending).

## 2. Up / down redundant (non-colour) encoding
Down = SOLID body (candle), 2 px stem (OHLC); up = OUTLINED body with 42% tint (candle), 1 px stem (OHLC). Hollow candle: colour = close vs previous close, fill = close vs open.
At L2: down spans solid, up spans dotted. Neutral grey for doji/zero-range. Volume columns: up tinted, down solid.

## 3. Forming bar
Dashed 1 px outline (2 on / 2 off) + 42% tint + text chip "forming mm:ss" (CMP-226, 1 Hz, aria-live off). No motion. Mirror name appends ", forming (not closed)".

## 4. A11y
Mirror text per bar: time, O/H/L/C, volume, up|down (+ forming). Aggregation level is text ("L2 agg 1.7 bars/px"), included in the chart rolling aria-label (CMP-180) and shown in SCR-046 as the same field. Nothing depends on animation. No account-derived colouring.
