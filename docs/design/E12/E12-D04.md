### 1.4 Rules stated once (every later row cites "R-n")

- **R-1 One list.** The strip is the same nine slots SCR-042 edits (D3-9, D03:54; T Tech "one source of truth"): one store, one order, one rendering. No second favourites list is built.
- **R-2 Only an explicit act starts a build.** Highlighting, arrowing and a check of a slot never build; `Enter` on a shown cost is the act (D3-3, D03:48).
- **R-3 Never silent.** A value a commit changes is named before the commit: the carried parameter, the fallback interval, the sync followers.
- **R-4 The working chart stays.** A switch keeps the previous frame until the new one paints; a failure keeps it (D02 D-1, OQ-16).
- **R-5 No bars from data that does not exist.** A mode unavailable for a symbol is never drawn for it (T AC2).
- **R-6 View state only.** No audit record; no confirm: every act is reversible view state and a build is cancellable (D02:29); no account, key, order or position data on this surface (T Sec; D03:446).
- **R-7 One copy deck.** E08-D05's state strings are reused verbatim; the tool diffs them.
- **R-8 The server enforces.** Hiding Record is not the control; the server's `recording:write` check is (C-2.12).

## 6. Cross-symbol validity: the probe, the fallback and its words (PROPOSED, owner approval pending (#2701); RULED BQ-9)

### 6.1 Unavailable

A mode is unavailable for a symbol with no recorded prints (C-24), or, for Volume and Delta, an unknown lot size (C-25). A flag-off or Renko-switch-off mode cannot be the current one. A shallow recording keeps the mode, with the built-from boundary (D3-4, D03:49).

### 6.2 The probe

Only when the chart's mode is non-time, after the 300<!--=BUDGET:count.rest--> ms rest on an active option, the client sends one `GET /market/data-coverage` (`22`:4737–4756), one in flight, cached for the session. The preview line reads C-29, "Checking recorded prints…" (D03:214), until it answers. The probe is bounded at 1<!--=RULE:probe.s--> s: past it, or on a failure, the state is unknown, no claim is made, and the commit falls through to F-BAR-5 (`13`:900–901, the BQ-9 default; D02 R-8 (:359) and D-13 (:37) leave the unknown case to F-BAR-3, a build, and D04-C5 records the departure). The probe never delays the commit of a time-mode chart: it does not run for one. On a time-mode chart a non-time slot therefore makes no T2 claim for missing prints unless the session cache holds that symbol's answer: its availability is unknown, and `Enter` on it commits and falls through to F-BAR-5. On a non-time chart, `Enter` before the answer sends the probe at once if the rest has not passed and holds the commit up to the bound, with C-29 shown; the commit then proceeds as known, or as unknown under F-BAR-5's words (SCR-047; `13`:900–901). The instrument route cannot answer instead: `recording_started_at` is a constant `null` there (`INS`:268–269; D04-G2).

### 6.3 The fallback target (PROPOSED)

The panel's last time interval before it entered the non-time mode; else `Settings.chart.default_bar_type` / `default_param` when that is time (`22`:20850–20851); else slot 1 of the default ladder, 1m (D02:182). Never a build.
