## 1. Purpose, method and the rules stated once

**Purpose.** E38's surfaces carry an unusual load: the environment must survive greyscale and colour-vision loss, the switch is a destructive-class action with an announced confirmation, and SCR-099's charts each need a table (`T` Context). This is the gate before E38-D06's hand-off.

**Method.** Every control, region and live region the parents name is one annotation row (§3). Each WCAG criterion `T` names (1.3.1, 1.4.1, 1.4.3, 1.4.11, 2.1.1, 2.4.3, 2.4.7, 2.4.11, 3.3.1, 3.3.2, 4.1.2, 4.1.3) is traced to the row or the parent line that answers it (§2). Where nothing answers, that is a finding.

- **R-1 Severity** (BQ-08). `Blocking`: a control on an E38 task path that a keyboard or screen-reader user cannot discover or operate, or the environment carried by colour alone. `Major`: a WCAG A / AA failure on the path, or an accessible name, focus rule or error association the parent leaves unspecified (AC 1); a G-T2 miss is Major (`DS`:15). `Minor`: a gap with a working path. `Info`: confirmed, accepted or routed.
- **R-2 Closing.** A finding closes one way: `fix: A-n` (an A-row in §10, its Old text or anchor found by content in its parent at its ref), `routed: <owner>` or `accepted: <reason>`. **Every Blocking and Major closes by an A-row**, and E38-D06's hand-off waits for each to be applied and re-reviewed (AC 3, BQ-09).
- **R-3 Honesty.** `(heuristic)` everywhere; no session, timing or quote exists.
- **R-4 The boundary.** The review checks; it does not design. A fix is the smallest that closes the criterion, and every new string is PROPOSED for the parent's owner (BQ-16).

## 14. The tool

`docs/design/_tools/e38_d05_a11y_review_audit.py` (`--check`, `--fill`, `--self-test`, `--repin-ruled`), stdlib only, run with `python3 -I`. It reads the parents with `git show` at their pinned heads and imports `verify_tokens`, `contrast_check` and `cvd_simulate` from the working tree, never re-implementing them. Default-deny: a gate that cannot read its input fails.

- **G-FINDING:** §9's rows in order, each severity from R-1, each closing an A-row §10 carries, a route or an acceptance; every Blocking and Major closes by an A-row; the heading's counts equal the rows.
- **G-NAMES:** the six screen sections exist, each with N rows in order, and every N row has a non-empty name.
- **G-PATH:** §4 has a W row for the pill, the popover, the typed confirmation, the step-up and the completion, each with a focus target and a visible-focus note.
- **G-T2:** every T2 reason is an E09-D09 §3.1 key's text at the base (its slot filled), a key's text on its cited line, or PROPOSED with its owner; every typed gate is V and carries no key.
- **G-CONTRAST, G-CVD:** every figure recomputed and equal; every `text` and `ui` pair above its floor in every theme; DEMO vs LIVE above the JND in every simulation.
- **G-AROW:** every A-row's Old text or anchor stands exactly once in its parent at its ref.
- **G-CITE:** every cite in range, on a non-blank line, equal to the pins file; the SHA anchors are the pinned refs.
- **G-HYGIENE:** no closing keyword, local path, URL or host, agent name, double-brace slot or public-text deny word in the review, the tool or the pins file.
- **G-SCOPE:** the diff touches only the review, the tool and the pins file.

The self-test applies one or more in-memory mutations per gate, each failing only its own gate, and confirms the text is restored.
