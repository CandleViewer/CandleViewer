### 1.4 Rules stated once (every later row cites "R-n")

- **R-1 Evidence or not Supports.** A row is Supports only when every artefact kind its class requires (§4) passes on every non-reserved screen, and no open finding in either register cites it (T AC1; MATRIX:13).
- **R-2 Missing evidence is said.** A row short of evidence carries the generated remark "evidence not produced …" with its screen count and the kinds not yet produced (T AC4).
- **R-3 Lower, never raise.** A reviewer may lower a row with a reason in the register's `overrides`; an override that raises is a FAIL (T AC4).
- **R-4 Generated, not written.** The report is generated from the registers that E47-D02 and E47-D12 read; nobody types a row (T Tech; REGPY:272).
- **R-5 One limitations register.** Every open E47-T01 finding is covered by exactly one row, keyed by its own id or its pattern's (BQ-7); the E47-D02 design findings a report row counts are not limitations until E47-T05 or E47-D12 routes them.
- **R-6 Owned or blocking.** A row with neither a fix ticket nor an accepted risk with an owner and an expiry blocks sign-off; a Level A row is never an accepted risk (never an accepted exception, BQ-7 ruled); the audit (E47-T01) is never a fix ticket (T AC5; `30`:1021).
- **R-7 Words first.** A statement limitation is what you notice, who it affects and what to do instead, in plain words; a criterion number only follows the words, never alone (T AC2).
- **R-8 Disclose generically.** An `internal` row appears in the statement only as its category's one generic sentence; statement text carries no host, id, key-like string or image (T Sec).
- **R-9 W3C words.** Conformance levels and the status are words from WCAG's own vocabulary, never a symbol, a colour or "compliant" (T a11y). The status is "Fully conforms" only when every row is Supports or Not Applicable, else "Partially conforms" (BQ-9).
- **R-10 The statement is data.** It is a versioned document loaded on demand; re-issuing it never changes code (T Tech).
- **R-11 Read-only for everyone.** The page has no write, no gated control and no personal field (BQ-12).

### 2.2 Columns, row order and remark grammar (frozen)

## 3. The honest-claims rule, mechanical (BQ-4; T AC1, T AC4)

For each row, in order: (1) Not Applicable if its class has a registered reason that holds (§2.3); (2) Does Not Support if no artefact of its class was recorded on any screen (an open finding is not evidence); (3) otherwise Supports if R-1 holds, else Partially Supports; (4) Does Not Support if an open blocker in the E47-D02 register cites it on a trading screen (SCR-050 … SCR-079); (5) a reviewer override may then lower it (R-3).
