## §H Session protocol (for the owner; none has been run)

Two screen readers (NVDA with Firefox, JAWS with Chrome) on a coded prototype of the footprint table, the ladder table and the profile table over a recorded fixture. Tasks: (1) open the table from the panel header with `Alt+T`; (2) read a footprint bar's five values in table mode (`Ctrl+Alt+arrows`); (3) sort a column and hear `aria-sort`; (4) apply and clear a filter and hear the count; (5) let three ticks pass with focus on a ladder row, sorted by cumulative depth; (6) pan the chart away and refresh with `Shift+R`. Record per task: completed or not, what was announced, the number of keystrokes; no timings or quotes are invented. The tree measurement at 100,000 bars (QA-4) and the engine lead's query-surface confirmation (D06-Q4) are recorded beside it.
