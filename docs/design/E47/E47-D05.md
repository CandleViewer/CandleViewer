### 1.4 Rules stated once (every later row cites "R-n")

- **R-1 Words first.** Every option's effect is stated in its description, in plain words that do not restate the label; a preview tile is never the only disclosure (`15`:2939; T AC1).
- **R-2 Runtime switch.** Every option applies within one frame as a root attribute or a flag: no panel remount, no data refetch, no reload (`14`:2480; `16`:167; T Perf).
- **R-3 Source in words.** Every tri-state row shows the effective value and its source as text — your system setting, your choice, or the product default — never by colour or position alone (T Tech).
- **R-4 Never discard an override.** An OS change re-resolves only a row that follows the system; an explicit choice stays and is never reset silently (T AC3).
- **R-5 One polite status per change.** Every control's state change is announced once, politely, by the control's own state; a source change adds one status line; nothing on this screen is assertive except a save failure (ASS:74–79; `14`:2479).
- **R-6 Previews obey the effective motion.** A tile animates only when the effective motion is full; under reduce it shows still before/after frames (T Tech; `05`:216).
- **R-7 Floors are unconditional.** The 24 px target floor and the focus ring hold with every option off; an option only raises them (`05`:100; `11`:5129; D04:237).
- **R-8 A delta is a G-row.** This PR changes no `apps/web` file; every difference from the shipped screen is routed to its code owner (BQ-1).

Effective value = user override ?? OS signal ?? product default (T Tech; MODEL:43–45). ## 12. Keyboard model and announcements on change (R3; T a11y; T AC4)

Initial focus: from a SettingsNav click focus stays on the item that opened the screen; from a deep link or reload it goes to the `h1` (`tabindex="-1"`, a route-change target only, out of the Tab order). Order: nav, the settings search, then each section top to bottom: each control, its "Reset" button when shown, the tile's Pause / Play sample button, the section's "Reset this section" button, then the Help links and the cheatsheet button. A RadioGroup is one stop with arrow keys and a roving tabindex (`15`:108); a Toggle is `role="switch"`, `Enter` / `Space` toggles (`15`:87). `Enter` in a field does nothing beyond the field (there is no submit: every change applies at once). The reset dialog returns focus to "Reset this section" on close (D04:312); if that button is gone because nothing in the section is modified any more, focus goes to the section's `h2` (`tabindex="-1"`). A standalone Reset button keeps the 24 px floor (R-7); only inline text links are exempt (`05`:100). Every state change is announced by the control's own role state; a source change adds one status (R-5).
