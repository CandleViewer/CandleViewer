### §C.2 The four new entries (D10-A3 … D10-A6; insert before `15`:3143, `### CMP-248 HistoryMarker (E12-D02 NC-2)`)

```markdown
### CMP-245 LiveRegion (utility; E47-D10)

- **Tier**: Atom (utility) · **Purpose**: the typed writer over the app shell's one live-region pair (E47-D07 §2), so no component hand-rolls `aria-live`.
- **Props**: `announce({ class, text, key })` — `class`: `significant-assertive` | `status-polite` | `ambient-polite` | `echo-polite` (E47-D07 §3.1); `silent` has no writer. `LocalStatus` (PROPOSED form): a container pre-rendered empty beside its control, `class`: `status-polite` | `echo-polite`, for E47-D07 R-1's four local kinds.
- **A11y**: Contract (E47-D10): non-interactive — a writer and a container, never focusable; ARIA — the pair's `aria-live` and `aria-atomic="true"` are the host's, mounted once by the shell, exempt from modal inertness; a `LocalStatus` is `role="status"` (or `role="alert"` once, for an error at its control). Consumes: CMP-246 (the containers).
- **Security**: a value E47-D07 classes `silent` cannot be passed (the type admits no text for it); a masked or secret-bearing field is `silent`.
- **Performance**: one app-level scheduler owns every class's schedule; no per-instance timer.
- **Storybook**: Classes, AssertiveQueue, SilentRefused, LocalStatus, UnderModal.
- **Tests**: unit (class → region and schedule; `silent` rejected at the type level), axe, interaction (writes captured by a test double).

### CMP-246 VisuallyHidden (utility; E47-D10)

- **Tier**: Atom (utility) · **Purpose**: the off-screen surrogate primitive (`05-accessibility-standard.md` §6.1): clip-based, never `display:none`.
- **Props**: `children` · `focusable?: boolean` (visible on focus, for skip links) · `as?` (the element).
- **A11y**: Contract (E47-D10): non-interactive — present in the accessibility tree, not on screen; a `focusable` instance takes CMP-039 when shown; ARIA — none of its own. Hidden is not absent: it never holds a value the visual layer withholds (a masked key, another account's order, a T3 affordance, a `silent` value). Consumes: CMP-039 (focusable form).
- **Tokens**: none (the `.cv-visually-hidden` technique: 1 px box, `overflow: hidden`, `clip-path: inset(50%)`).
- **Storybook**: Default, FocusableSkipLink, InTable.
- **Tests**: unit, axe; a DOM-dump test that a withheld value is absent, not hidden.

### CMP-247 MotionVariant (utility; E47-D10)

- **Tier**: Atom (utility) · **Purpose**: the one reader of the effective motion tier (E47-D08 §2): full, canvas calm, reduced, resolved once by the theme runtime into `data-motion`.
- **Props**: `useMotionTier(): "full" | "canvas-calm" | "reduced"`; CSS: the recipe pair `--cv-recipe-<name>-safe` / `-reduce` on `:root[data-motion]` (`16-design-system-brief.md` §7).
- **A11y**: Contract (E47-D10): non-interactive — a hook and a stylesheet convention; ARIA — none. No component reads `prefers-reduced-motion` itself; a guarded `:root:not([data-motion])` media block is the OS fallback before the runtime writes the attribute. Consumes: none.
- **Performance**: one subscription to the resolver's store per consumer; no `matchMedia` listener per instance.
- **Storybook**: Full, CanvasCalm, Reduced.
- **Tests**: unit (each tier), visual per tier.

### CMP-248 NonColorState (utility; E47-D10)

- **Tier**: Atom (utility) · **Purpose**: returns the channel set (glyph, sign, pattern, word) E47-D03 §5 assigns to an encoding and surface, so no component draws its own.
- **Props**: `NonColorState({ encoding, value, surface? })` — `encoding`: a key of `tools/contrast/encodings.json`.
- **A11y**: Contract (E47-D10): non-interactive — it produces the word or glyph its host renders; ARIA — the word is text; a glyph beside a word is `aria-hidden`, a glyph alone carries the word as its name. Consumes: none.
- **Storybook**: BuySell, Pnl, OrderStatus, ConnectionHealth, Imbalance, GlyphOnly.
- **Tests**: unit (every encoding of `encodings.json` returns a non-colour channel), visual in the high-contrast theme.
```
