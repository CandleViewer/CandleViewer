## 4. Keyboard and focus (AC Focus; R3)

### 4.1 Focus order per screen

- **SCR-055:** header actions → the window control, one roving stop (`←` / `→`, `Home` / `End`) → the alert affordance → the `Alt+T` table when open; the readout is not a stop (`D02`:311–314).
- **SCR-056:** header actions → the controls row, one roving stop over the pills → the Recompute history trigger when shown → the filters row → the zone grid (`↑` / `↓` move the row cursor; the divider row is skipped; a re-rank never moves the cursor, focus follows the zone id; `Enter` locates; `Esc` releases) → the event feed (`role="feed"`) (`D02`:315–320). **The row cursor** is the APG grid's roving row (R3: named).
- **SCR-057:** header actions → the regime chip (the host button; `Enter` opens SCR-058 at the regime section) → the breakdown disclosure (`aria-expanded`) (`D02`:321–323).
- **SCR-058:** on open, focus to the section heading the chip named (`tabindex="-1"`); the close button, then the links in order; non-modal; `Esc` closes and focus returns to the chip (`D02`:324–326; `D04`:303).
- **SCR-059:** on open, the first fieldset's Toggle or the fieldset Flow A targets; `Tab` traps inside; `Enter` in a field commits the field and applies nothing; `Esc` cancels (with unsaved changes, the prompt) and focus returns to the opener (`D02`:327–332).

### 4.2 Visible focus

Every stop takes the double ring, 2 px `color.focus.ring` outside a 1 px halo in the host surface at `border.focus` (`D03`:295; `D04`:303); CR-7 measures the ring on the panel and the overlay (§7).

### 4.3 The armed-rule confirmation (`T` Security)

A CMP-044 `alertdialog`, title "Apply detector changes?", **Cancel focused first**, Confirm "Apply changes" (names the effect), no hold, no typed token; `Esc` and Cancel return to the dialog with nothing sent (`D04`:216–218). The restatement box (before → after) and the rules list are the dialog's description through CMP-044's `restatement` prop (`15`:519). The fail-safe CF-2 lists every visible armed rule with its scope sentence (`D04`:223). Operable by keyboard alone and read in full by a screen reader `(heuristic)`: compliant.
