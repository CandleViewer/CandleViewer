## 17. The tool and the mutation list

`docs/design/_tools/e25_d07_handoff_audit.py` (`--stage deck|full`, `--check`, `--json`, `--self-test`, `--repin-ruled`), stdlib only, run with `python3 -I`, default-deny. The stage is named, never chosen by which files exist: `--stage deck` needs the deck and the tool and runs G-STAGE, G-DECK, G-PROV, G-FROZEN (its deck part), G-HYGIENE and G-SCOPE, naming the rest as not run; `--stage full` (the default) runs every gate:

- **G-STAGE:** every file the stage needs is present.
- **G-DECK:** the deck parses; the header first; every row has every field, a unique `detectors.*` key, a known kind, status, provenance and consumer; a `merged` row cites a merged file, a `RULED` row names its ruling; every row's text, or its `quote`, is on its cited line at the base; a row whose source marks it PROPOSED is not `merged`.
- **G-PROV:** §9.3's rule over every row; no "Est." anywhere.
- **G-FROZEN:** the frozen ids run FZ-1 … FZ-n; at the full stage §9.2 lists them in order with their keys, both `T` Security controls appear, and each freeze reads PROPOSED.
- **G-COMP:** every component on the five `14` Components lines has a §3.2 row, and every `15` cite there is its heading.
- **G-BIND:** §5 holds D02's DB-1 … DB-28 in order, each source cite on its own DB row, each with a CMP id and a missing / stale reading.
- **G-STATE:** §6's id ranges equal D02 §9's ids per screen.
- **G-A11Y:** §8.1 has the five screens, each focus cite on its screen's D06 line; §8.2 holds D06's F rows with their severities; every quoted D06 narrative is a deck row (N-11 by C-1); the F-01 carry is on its deck row.
- **G-EVENT:** §12's events are the five `14` Analytics lines' events, each on its screen.
- **G-DERIVED:** every BUD, COUNT and DATE anchor is computed from its source.
- **G-CHECKLIST:** §16's rows are the five `14` checklists, item by item.
- **G-OPEN:** every §14 row has an owner and a due date.
- **G-AROW:** every hand-off §C row's line is the pointer it follows; A-n run without a gap.
- **G-CITE:** every cite in range, on a non-blank line, and equal to the pins file's hash.
- **G-FILLED:** no placeholder in the pack, the hand-off or the deck.
- **G-HYGIENE:** no closing keyword, local path, URL, agent name or public-text deny word in the texts, the tool or the pins.
- **G-SCOPE:** the diff touches only this ticket's five files (the deck and the tool at the deck stage).
