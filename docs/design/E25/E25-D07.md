## 17. The tool and the mutation list

`docs/design/_tools/e25_d07_handoff_audit.py` (`--stage deck|full`, `--check`, `--json`, `--self-test`, `--repin-ruled`), stdlib only, run with `python3 -I`, default-deny. The stage is named, never chosen by which files exist: `--stage deck` needs the deck and the tool and runs G-STAGE, G-DECK, G-PROV, G-FROZEN (its deck part), G-HYGIENE and G-SCOPE, naming the rest as not run; `--stage full` runs every gate. `--stage` is required, never defaulted, and `--repin-ruled` refuses outside the full stage. The deck stage's `--check` is PR 1a's gate: on PR 1b, which also carries the spec, the hand-off, the pins and `14`, its G-SCOPE names those four files by design, and the full stage is the gate.

- **G-STAGE:** every file the stage needs is present.
- **G-DECK:** the deck parses; the header first, its key naming PROPOSED; every row has every field, a unique `detectors.*` key, a known kind, status, provenance and consumer, and an `owner` from the parents' lanes; a `merged` row cites a merged file; a `RULED` row's `ruling` is a `#n BQ-n` or `#n comment n` id that its source line names; every row's text, or its `quote`, is on its cited line at the base. A row its source line marks PROPOSED is not `merged`: marked next to the string, by the string's aligned segment of the status cell, by a status cell that opens a clause with PROPOSED, or by the tool's reading of a prose status cell (`D04`:406, :412), where a RULED reading needs a RULED row.
- **G-PROV:** §9.3's rule over every row; a row whose text holds "(estimated)" is `estimated`; no "Est." anywhere.
- **G-FROZEN:** the deck's frozen rows are the tool's register, FZ-1 … FZ-15, each id once on its key; at the full stage §9.2 lists them in id order with their keys and cites, each with the control the register gives it (D04 §11), both `T` Security controls appear, and each freeze reads PROPOSED.
- **G-COMP:** every component on the five `14` Components lines has a §3.2 row, and every `15` cite there is its heading.
- **G-BIND:** §5 holds D02's DB-1 … DB-28 in order, each source cite on its own DB row, each field cell's names on that row, each with a CMP id and a missing / stale reading; DB-26 and DB-27 keep the frozen behaviour's words (§9.2).
- **G-STATE:** §6's id ranges equal D02 §9's ids per screen; §6 states E17-D01 D2's feed precedence word for word.
- **G-A11Y:** §8.1 has the five screens, each focus cite on its screen's D06 line and each narrative cell D06 §5's rows for its screen (an `all` row on the three panels); §8.2 holds D06's F rows with their severities; every quoted D06 narrative is a deck row; a carried row speaks no longer in its finding's defect form, is PROPOSED and names its request, and §8.2 names it.
- **G-EVENT:** §12's events are the five `14` Analytics lines' events, each on its screen.
- **G-DERIVED:** every BUD, COUNT and DATE anchor is computed from its source; `T`'s four budgets equal `14`'s.
- **G-CHECKLIST:** §16's rows are the five `14` checklists, item by item.
- **G-OPEN:** every §14.1 row has an owner and a due date no later than Sprint 13's first day; every open G / Q row of D01 … D06 and D01's open AC rows are listed by id; §14.2 closes exactly the tool's reading, each on the cited line that closes it; no id is unknown or listed twice.
- **G-AROW:** every hand-off §C row's line is the pointer it follows; A-n run without a gap; §C's anchors are the tool's permitted list (`CAT_ANCHORS`).
- **G-CITE:** every cite in range, on a non-blank line, and equal to the pins file's hash.
- **G-FILLED:** no placeholder in the pack, the hand-off or the deck.
- **G-HYGIENE:** no closing keyword, local path, URL, agent name or public-text deny word in the texts, the tool or the pins.
- **G-SCOPE:** the diff touches only this ticket's five files and, at the full stage, `14` at the listed anchors alone: the working tree's `14` is the merge base's with each A-row's New on its own line after its hi-fi pointer line (`CAT_ANCHORS`, A-1 … A-5), and any other `14` change fails, which the self-test proves by editing a line no A-row lists. The deck stage stays `14`-strict (the deck and the tool only).

The self-test applies one mutation per gate at least, each failing only its gate, probes that `--repin-ruled` refuses at the deck stage, then checks the texts are restored byte for byte. The list is the tool's `MUTATIONS` and `DECK_MUTATIONS`, printed by `--self-test`.
