## 2. Voice and tense (V-n; AD-2, AD-3)

- **V-1** Second person, present tense, active voice: "Your request is held", not "The request has been held".
- **V-2** Fact, then cause, then action — SCR-151's anatomy (`14` :3104): heading states the fact, one sentence the
  cause, one control the action, or a sentence saying no action is available to this role (`14` :3107).
- **V-3** No blame: state the constraint, not the user's mistake — "This value must be between 1 and 100", never
  "You entered an invalid value".
- **V-4** No exclamation marks; no "please", "sorry" or "oops"; no humour on a safety surface.
- **V-5** Jargon only with its CMP-069 InfoPanel link (`15` :780); a lexicon term (§3) is not jargon.
- **V-6** Sentence case for headings, buttons and menu items; the environment badge, the status words and the
  safety cluster keep their merged uppercase ("LIVE", "ARMED", "FREEZE…") (`05` :150, :34; D03E10 :79); in a
  name or an announcement each such word has a lower-case spoken form, as
  `E36-D05:strings.rules.list.spoken.armed_demo` does (P-05), so no screen reader spells it.
- **V-7** "…" ends a control that opens a dialog before it acts ("FREEZE…", D03E10 :79), never one that acts.
- **V-8** A button names its effect with a verb and the object: "Flatten first, then delete", never "OK" or "Yes".

## 4. The error-message standard (AC 2; E-n; AD-4)

- **E-1 Four parts.** Every user-facing error states **what happened**, **why** (the cause, when it is known), and
  **what to do next** (one action, or that nothing is needed), in that order (V-2); the fourth part is the Ref.
- **E-2 The Ref.** The opaque id's visible label is CMP-089's "Ref {instance}" (`15` :1008), on every surface
  (F-15). Its source: an HTTP problem's `Problem.instance` — the opaque `urn:cv:req:{uuid}` (`22` :18763–18767) —
  only when a problem body arrived; the WS frame's `request_id` (`23` :1609) the same way; a render crash has no
  problem body, so CMP-091 shows the boundary's `correlationId` (`15` :1027). Never synthesised, never shown empty
  (D09 :161). `instance` is optional in the schema (`22` :18756): a REST error without it, and a
  network failure, show no Ref (G-1). The Ref has a "Copy reference" control (keyboard operable) and is exposed
  as one labelled value ("Reference"), never read out inside a live message.
