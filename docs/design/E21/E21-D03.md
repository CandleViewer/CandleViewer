A field's value is never announced as it changes; an error found at Save is read by moving focus to it (CMP-027 `live: "off"`), and an error found on blur, when focus has already left the field, is written once through the status node (§9.1). A tab switch validates and announces nothing beyond that blur. The tile's `role="img"` name changes with every edit and is not a live region. ## 8. The apply model (boards 02, 08)

### 8.1 Before Save

Every change previews in the tile (R-1). A book key (R-2) shows W-4 under its control at once, as plain text in the tabpanel, announced once through the status node (R-5). A visual key shows nothing beyond the tile: no rebuild wording, because colour is a uniform update ≤ 1 frame that keeps the frame buffer (`14`:1253).

### 8.2 Save and the rebuild (AC 3)

Save validates (§9); with no error it enters CMP-043's busy state (the primary action `loading`, `15`:509) until the server answers the book key's `ctl` with `ctl_ok` (`23`:719). While busy, Save stays focusable with `aria-disabled="true"` (never `disabled`, so focus is not dropped), the dialog body carries `aria-busy="true"`, every field is `aria-disabled="true"`, and W-38 is written once through the status node (R-5). If neither `ctl_ok` nor a refusal arrives within the client's request timeout (its value G-6), the busy state ends, the fields return and §8.3 applies with W-9. On `ctl_ok` the dialog closes and returns focus to the control that opened it or, if that control is gone (the pane closed or re-rendered), to the panel's depth control, else the pane container. The panel then shows its pending text until the fresh `snap` applies: for a tier change D02's tier notice W-5 (D02:402); for a row-aggregation or Columns change the panel's pending chip text W-36 (D03E17:208) — never D02's resync scrim (D02:226), never Stale or Resyncing (D03E17:208). A Save of visual keys only closes at once. `dom.settings_changed {key}` fires per changed key and `dom.depth_tier_changed` on a tier change (§14.1).

### 8.3 Refusals at Save (T4)

A `ctl` refused for the rebuild budget (`resync_rate_limited`, `23`:731) or a 500 tier refused for the cap (`23`:765) changes nothing: the dialog stays open, the fields keep the user's values, the busy state ends, and W-9 shows inline under the Save row with focus moved to it (T4 at the point of action, not T2); the node takes `tabindex="-1"` to be focusable and carries no `role="alert"`, since focus reads it. W-9's key is PROPOSED for E17-D01 §7's owner (D03E17:211 routes the refused-`ctl` copy there).

### 8.4 Save gated (T2; board 08)

Save is a write (D03E17:289). While viewing as, or without `workspaces:write`, Save is T2 (R-3) in rendering 2a, legs in E09-D09 order, the view-as leg first: W-32 `rbac.view_as`, then W-33 `rbac.permission` with the verb "save workspaces" (D09E09:114).
