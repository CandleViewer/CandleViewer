## 6. The before/after diff language (SCR-135, SCR-136, SCR-122's change summary, SCR-145's history)

- **Input.** `detail.before`, `detail.after` (an object or null) and `detail.elided` (Y:20114-20130), read with the
  record's `outcome` and shape (the table's first three rows; CG-30). `04:1306` asks writers for field-level diffs;
  these store whole states and requests, so the renderer computes the changed keys. SCR-122's summary takes the inline
  form: a role → `value`, a grant → Added / Removed, a cap → `value` with its unit (D03 UD-3; §20).
- **Two forms.** _Inline_: one line per changed field, "value: OFF → ON" (a `flags.change` records `overrides` as an
  object, svc/admin/flags/writes.py:256-257, :274); the arrow is `aria-hidden` and the line reads "changed from OFF to
  ON" (compact rows, SCR-122's summary, flag history); request-shape lines read `diff.inline_requested`; a fact or a
  result reads "path: value", a withheld or hidden value its words alone. _Full_: a `<dl>` with one term per changed
  field (its path) whose description is a nested `<dl>` with the visible terms **Before** and **After** (row expansion
  and SCR-136; `14:2600`; #887 A11y notes).
- **Rules.** Unchanged fields fold into the `diff.unchanged_n` disclosure; "Added", "Removed" and "Changed" are words
  in a status column, never a colour or strike-through (it means delisted, E08-D01:86); an Added field shows After only
  and a Removed one Before only, never `diff.none`; a null `before` pairs every After field with `diff.no_before`, and
  "Created" / "Removed" need a registry map naming the action so (DJ); a withheld `before` beside a served `after` reads
  `diff.withheld` once under Before while After lists the served fields, with no status word (a cap withholds one
  state, an overrun page budget that state and every later one: svc/audit/query.py:55-59, :78-84; Y:20119-20121);
  nested objects keep their path ("overrides › 9f1c…"); lists compare as whole values; a value over 120 characters
  shows its first 120, then `diff.full`; Copy and the disclosure are cells only where the row has them; numbers keep
  §1's separators and a flag's boolean reads ON or OFF.
