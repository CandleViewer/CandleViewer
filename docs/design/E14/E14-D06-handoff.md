# E14-D06 — handoff checklists (the position-tool read-out, CMP-191, CMP-107; #350)

Per `docs/plan/16-design-system-brief.md` §11.4 and §13.3 item 8 (`02` §4.2): this SCR ticket **introduces** one component contract — the position tool's **read-out** (uncatalogued today: CMP-191's `tool` enum has no position value, CMP-197 is `aria-hidden`, CMP-036 rows are composed inside it; **no CMP id is invented here — `15`'s owner / E14-D08 assigns one**) — and **changes** two: **CMP-191 DrawingToolOverlay** (a three-anchor tool with labelled anchors, a Send-to-ticket action, the invalid-geometry state and the switch) and **CMP-107 OrderTicket** (a `prefill` input and its provenance line), so each gets a block below; the components it only composes (CMP-036 KeyValueRow, CMP-020 NumericText, CMP-022 Kbd, CMP-019 Icon `lock`, CMP-079 RbacGate, CMP-075 EnvBadgeLocal, CMP-106 ProfileBadge, CMP-158 SafetyInvariantNotice, CMP-232 LimitsChip, CMP-139 EnvironmentAwareOrderGuard) get one placement line each and link their own checklists. The consumers are **E14-D08 (#352)** — not blocked by this ticket, so the blocks are handed to it explicitly — and **E14-D12 (#355)**. **Deviation from the §11.4 block shape (the lane shape of E30-D03):** Tables 1–5, the Density table and the Essential-exceptions table appear once each with a leading `Component` column instead of once per block. Every line is `[x]` with its evidence or `[ ] N/A — <reason>`; BLOCKED-PENPOT lines are N/A with the reason until hpe-worker-1 draws (text-first; the boards land in a second PR).
