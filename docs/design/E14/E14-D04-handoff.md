# E14-D04 — handoff checklists (the SCR-037 properties popover, CMP-031 and the mixed-value state of the shared field atoms; #318)

Per `docs/plan/16-design-system-brief.md` §11.4 and §13.3 item 8 (`02` §4.2): this SCR ticket **introduces** one composition and **changes** two component contracts — **the SCR-037 properties popover** (composed on CMP-017 Popover; no catalogue id exists and none is invented — E14-D08 / `15`'s owner decide whether it becomes an organism, spec G-T9), **CMP-031 ColorSwatch** (the closed drawing-palette set the host passes, E13-D03's radio anatomy and name grammar, the selected indicator, the "Mixed" and "Custom colour" states, the T2 state) and **the mixed-value state of the shared field atoms** (CMP-005 Checkbox's `indeterminate` as the popover's mixed boolean, CMP-008 NumericStepperInput and CMP-010 Slider showing "Mixed" through `aria-valuetext`, CMP-009 Select's "Mixed" trigger text) — so each gets a block below; the components the popover only composes (CMP-003, CMP-004, CMP-006, CMP-007, CMP-016, CMP-019, CMP-026, CMP-027, CMP-036, CMP-038, CMP-039, CMP-040, CMP-041, CMP-043, CMP-045, CMP-058, CMP-065, CMP-079) keep their catalogue contracts and get placement lines only. Consumers: **E14-D08** (#352 — the `15` text A3–A9 and the DS change requests CR-1…CR-7), **E14-D12** (#355 — the pack), **E14-D10** (#354 — the keyboard / name tables and the copy deck), **E14-S10** (#432 — the build).
