### 1.3 Rules stated once (every later row cites "R-n")

- **R-1 C-2.11 is a hard constraint.** The footprint reads public market data only and is environment-neutral: no environment badge, no environment control and no account context on these surfaces (D02:408, `SCR-030/fp-demo-live`: the footprint is identical in demo and live; the status-row env badge there is global chrome); the global chrome is the only environment carrier. Violated if a board or an A-row New puts an environment badge, control or account context on these surfaces, or draws demo and live differently (G-ENV, M-23).
- **R-2 Geometry, registered patterns and glyph carry; colour reinforces.** Every meaning has a geometry, a registered pattern or a text carrier (D02:753; `16`:194); a pattern is a registered id that keeps its registered meaning and never carries a side (D05E11 §7): the zone's tested bracket is `pattern.dashed.tested`, its broken lane `pattern.hatch.absent` (BQ-2), the cell flag `pattern.outline.imbalance` (solid), the L2 sign `glyph.notch.delta`; no other dash, hatch or hollow mark appears on a footprint mark; a fill or hue only reinforces. Violated if a dash, hatch or hollow mark appears on a footprint mark other than those ids at their registered meaning, or a pattern carries a side (G-AC1, G-AROWS; M-16, M-17, M-29).
- **R-3 Tint by side, density changes spacing.** The sell side (bid, `24`:819) takes the sell ink and the buy side (ask) the buy ink, named by side, never by the inverted token pair (C-1); density changes padding and the size class only (D02E11:113), never a colour, a mark or a word. Violated if a cell's ink follows `color.footprint.bid` / `.ask` rather than its side, or two densities differ in a colour, mark or word (board 02; C-1).
- **R-4 The T2 rule.** A control these surfaces gate is T2 (D09E09 §2.2, §9): native role and full label (G-T2.1a); `aria-disabled="true"`, never `disabled`, in the Tab order, a menu item arrow-reachable (G-T2.1b); the reason node in the DOM at mount, linked by `aria-describedby` (G-T2.1c), in rendering **2a inline** unless §1.4 names the sentence form; CMP-079 RbacGate wraps it and the CMP-019 `lock` glyph (`decorative=false`, name "Not available") leads the label (G-T2.1d); label `color.text.tertiary`, reason `color.text.secondary`, a primary fill `color.surface.raised` with a `color.border.default` hairline, never `color.text.disabled`, never `opacity.disabled` (G-T2.2; D02:615); `Enter`, `Space` or a bound key changes nothing and re-shows the reason with one polite announcement (G-T2.3); every reason a D09E09 §3.1 key with its §3.2 verb, or a PROPOSED state string with its vocabulary owner named (G-T2.4); a panel read-only for the session carries one header notice every gated control points at (G-T2.5); every section showing a gated control cites R-4 (G-T2.6). Cell text is full, never compact: `1.2K` is never drawn in a cell (D01E06:147; D02 A-25; M:292). Formats are computed per cell on data update into a cached glyph run (`26`:287), so the set is closed and small. The canvas draws only `26`:284's set (printable ASCII plus `×`, `▲`, `▼`): its minus is ASCII `-`; the DOM may keep `−` (U+2212) as CMP-109's as-built does, and a screen reader hears "minus" or "plus" from the mirror words (W-3), never the glyph. Every format is drawn in one text pass (R-7).

### 4.1 The formats

| Field                   | Magnitude                  | Format                                                             | Example (canvas)                        | Width (glyphs) |
| ----------------------- | -------------------------- | ------------------------------------------------------------------ | --------------------------------------- | -------------- |
| volume, bid, ask, total | any                        | integer at BTC unit scale, comma thousands, right-aligned per side | `12,450`                                | ≤ 6            |
| delta                   | below 1,000 in magnitude   | one decimal, signed, `▲` / `▼` first                               | `▲ +812.5`                              | ≤ 8            |
| delta                   | 1,000 or more in magnitude | integer, comma thousands, signed, `▲` / `▼` first                  | `▲ +1,206`                              | ≤ 9            |
| `bid_ask` pair          | —                          | bid, `×`, ask; each right-aligned in its side-cell                 | `1,204 × 2,410`                         | ≤ 15           |
| `delta_total`           | —                          | the delta format, `/`, the volume format                           | `▲ +1,206 / 3,614`                      | ≤ 18           |
| bracket short label     | —                          | `×`, depth, side word, state word when not active                  | `×3 buy tested`                         | ≤ 15           |
| bracket full label      | —                          | the short label's parts, "stack", the range, the state word        | `×3 buy stack 64,010.0-64,012.9 active` | ≤ 39           |

Widths are maxima for five-digit volumes and a two-digit stack depth (D01E06:143). The delta's two tiers reconcile E06-D01's `+4.3` and `-8,192` (D01E06:143) with D02's integer `▲ +1,206` (D02:252) as one rule (C-4). A zero delta draws `0`, with no sign and no `▲` / `▼`. A level's volume below 0.5 BTC draws `0` in the cell; the tooltip, drawer and mirror carry full precision (OQ-1).

### 4.2 What invalidates a glyph run

| Event                                                         | Why the run is rebuilt           |
| ------------------------------------------------------------- | -------------------------------- |
| a cell's values change (a trade, a snapshot)                  | the string changes               |
| `cellMode` changes                                            | the fields and the format change |
| the size class changes (density or the text size, D02E11:113) | the advances change              |
| the rows aggregation changes                                  | every cell is re-bucketed        |
| a level crosses the delta tier at 1,000                       | the decimal appears or goes      |

Theme, palette and zoom never rebuild a run: colour is a per-instance attribute (`26`:286) and LOD hides runs without rebuilding them.
