The visible DOM per chart is the chrome (toolbar, status row, strip, legend), one corner badge, one tooltip, one drawer
and one menu, never an element per cell. Cells, outlines, brackets, labels, markers, the cap and the level box are
canvas (SDF text and instanced quads, `26` §3.7, §4), hit-tested in the worker (`26` §3.9). The off-screen mirror,
visible cells only in the strict sense, holds bar rows for a window plus, on `Enter`, a ≤ 40-node window of the cursor

force per-cell DOM; E06-D03 F15 supersedes both (A-20, A-24), and no frame here relies on them.
