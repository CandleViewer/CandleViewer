## 1. Purpose
The only E09 surfaces that sit on top of a live trading workspace. Chassis designed once (alertdialog, flat
60% scrim, no blur, focus trap) and reused for SCR-149.

## 2. Interruption policy (needs Architect + Owner sign-off)
- Frozen: all input to chart, ladder and ticket (visibly non-interactive). Moving: market data keeps streaming
  underneath; WS subscriptions are PAUSED, not torn down (no reconnect storm on resume).
- Order entry disabled while locked. Armed one-click trading is disarmed at lock/absolute expiry and is never
  restored automatically; a draft ticket is retained but unarmed.
- Alerts/toasts: still evaluated server-side; the UI queues and shows them after unlock (no content over the lock).
- In-flight order at lock: server completes it; result is reconciled via `GET /api/v1/orders?status=open` on resume.
- Native exchange stop-losses are unaffected (C-2.6).
- On return: same workspace, scroll position and layout; focus returns to the triggering control.

## 3. States
CMP-098 warning at 60 s with keyboard-operable Extend (WCAG 2.2.1); no lock frame appears without it.
SCR-005 as listed above. SCR-006: code-only; code + typed confirmation restating the target verbatim
(Confirm disabled until both valid); valid-grace with remaining TTL from a server expiry; failure 1 and 2;
3rd failure abandons the action and shows a read-only downgrade banner (5 min, vocabulary from E09-D09) with a
high-severity audit annotation; no-grace variant (Live enablement, kill-switch disable) shows no grace at all.
SCR-149: password + TOTP, 15-minute unlock, "Why am I seeing this" text, wrong credentials (generic message),
lockout, expiry during admin edit (content preserved, save held), unlocked indicator in admin chrome.

## 4. Data
`POST /api/v1/auth/step-up` -> `stepUpToken` (5 min); admin token 15 min; all remaining-validity values come
from server-issued expiry. Audit: `auth.session.expired`, `auth.session.reauth`, `auth.stepup.granted|denied`,
`admin.session_elevated`.

## 5. Interactions and hotkeys
Enter submits; Esc does not dismiss SCR-005; Esc cancels SCR-006/SCR-149 to a safe no-op (SCR-149 cancel returns
to the non-admin app). Tab cycles inside the dialog. CMP-098: Enter/Space on Extend (hotkey: any key press is
NOT an extend; only the explicit control).

## 6. A11y
`role="alertdialog"`, accessible description names the exact action/target; focus starts on password / code
field; trapped and returned on close; failures `aria-live="assertive"`; CMP-098 `role="alert"` once, countdown
not announced per tick; colour never the only signal; `prefers-reduced-motion` respected.
