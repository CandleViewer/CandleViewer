### 3.2 What an owner reset does (BQ-8: RULED (orchestrator, 2026-10-29, #2701 ledger 1 row 8))

An owner reset marks the existing credential must-change and neither clears nor sets the password: the user signs in with the current password and the second factor (`13`:685), then lands on SCR-004 with the current-password field. **The trade-off, for the owner:** under this reading a reset does nothing against a compromised password (whoever holds it still signs in and then chooses a new one); the lever for compromise is disabling the user (`04`:846). The reset's own contract is G-5.
