# E49 GA regression pack: deliberate gaps

Ticket: E49-Q01 (#1335), S1. Each row names Must stories of `docs/plan/11-user-stories.md` that no pack test
covers, read by `apps/web/test/e2e-ga-pack.test.ts` (map: `docs/qa/e49-ga-regression-pack.md`). A row
leaves when a pack test covers its story. Risk acceptances stay PROPOSED until the owner accepts them (the
#2701 digest). Route owners are those of `apps/web/src/routes/manifest.ts`.

Reason words. `unbuilt`: no source implements the story's screens. `unmounted`: its code exists, no entry point
imports it. `partial`: one of its screens is mounted, the acceptance is not met. `incidental`: a citation that
is a comment or a link to a stub, so it does not count as built. `below E2E`: backend-only, held by the named
suites. `parked`: the route renders a stub and the row names its owner. A story a pack test cites only by
scenario (`US-<D>-<nnn>#<Scenario>`) is never covered: its row is `partial` and names every scenario no
pack test cites.
