### 10.1 Verdict agreement and Cohen's κ

**Coding.** Each cell is one (screen, SC) verdict collapsed to four categories: `pass` (including `pass (exception: …)`), `fail`, `n/a` (any reason) and `unreachable`. The `scope: built part` tag on partial rows is ignored for coding. No `unreachable` cell occurs (the sample is all reachable), and no compared cell is `not run`, so the observed categories are `pass` and `n/a` (primary) and `fail` / not-fail (secondary). The first rater's register holds explicit verdicts only for the six WCAG 2.2 criteria per screen; for the other 49 SCs it records findings, not a pass grid. So:

- **Primary** — the six WCAG 2.2 criteria, explicit verdicts from both raters: n = 16 × 6 = **96** cells.
- **Secondary** — all 55 SCs, binary: the first rater's cell is `fail` when an **open** register finding (its `screenId` or an `alsoOn` id) or a `wcag22` verdict fails that SC on that screen, else "not-fail"; the second rater's cell is `fail` when its verdict is `fail`. n = 16 × 55 = **880**. The first rater's "not-fail" is **implicit** on the eight sampled screens that had no deep pass (no per-SC judgement was made there beyond the six 2.2 criteria), so this κ is a lower-quality measure and is reported only beside the primary one.
